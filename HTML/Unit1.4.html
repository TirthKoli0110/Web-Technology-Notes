WWW

The World Wide Web is an application that operates using the Internet.

Important points

  1. User-friendly access

    Provides a user-friendly way to access information.

  2. What users can access

    Websites, webpages, images, videos and other multimedia (see the next section).

  3. Hyperlinks

    Uses hyperlinks to connect webpages.

  4. HTTP

    Uses HTTP for communication between web browsers and web servers.

  5. Client-server model

    Follows the client-server model.

  6. Clients and servers

    Web browsers act as clients and web servers provide the requested content.

Users can access

  1. Websites

    Collections of related webpages.

  2. Webpages

    Single documents shown in a browser.

  3. Images

    Pictures and graphics on webpages.

  4. Videos

    Video content streamed or played in the browser.

  5. Other multimedia

    Audio, animations and other media.

Remember

  1. Internet vs WWW

    Internet is the infrastructure; WWW is a service running on that infrastructure.
