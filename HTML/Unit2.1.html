What is HTML?

  1. HTML = HyperText Markup Language

  2. Standard markup language used to create web pages.

  3. Describes the structure of a webpage.

  4. Uses tags to display content.

Examples of Tags

Heading

This is a paragraph.

Visit Google

Basic HTML Structure

  1. <!DOCTYPE html>

    Declares HTML5 document

  2. <html>

    Root element

  3. <head>

    Stores page information

  4. <title>

    Browser tab title

  5. <body>

    Visible webpage content

HTML Elements

An HTML element consists of:

Start Tag + Content + End Tag

Example

  1. <p>

    Start tag

  2. Hello World

    Content

  3. </p>

    End tag

Empty Element

This is the first line.

Web Browser

A browser reads HTML code and displays it as a webpage.

Examples

  • Google Chrome
  • Microsoft Edge
  • Mozilla Firefox
  • Safari

Note: The browser displays the webpage, not the HTML tags.
