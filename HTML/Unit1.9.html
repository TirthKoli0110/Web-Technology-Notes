Web 2.0

Web 2.0 refers to the modern, interactive and social form of the Web. Unlike the older web, where users mainly read information, Web 2.0 allows users to read, write and interact.

Main features

  1. User-generated content

    Users create the content, not only website owners.

  2. Interaction

    Users can interact with websites and with each other.

  3. Collaboration

    Users can work together online.

  4. Social networking

    Users build profiles and communities online.

  5. Sharing

    Users can share content with others.

  6. Comments

    Users can give feedback and join discussions.

  7. Uploading content

    Users can upload text, images and videos.

  8. Connecting with other users

    Users can find and connect with other people.

Easy definition

  1. Remember this

    Web 2.0 = Interactive and social Web
