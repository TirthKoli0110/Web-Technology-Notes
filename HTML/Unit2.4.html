These are the basic HTML tags used to build every webpage, with the purpose of each one.

18. Important HTML Tags

Tag Purpose
<html> Root element
<head> Page information
<title> Browser title
<body> Visible content
<h1> - <h6> Headings
<p> Paragraph
<a> Hyperlink
<img> Image
<br> Line break
