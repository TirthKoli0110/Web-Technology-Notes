HTML Colors

Web Technology  /  HTML  /  Colors

HTML colors are used to change the background color, the text color and the border color of elements.

Color Formats

FormatExampleOutput
Color NameTomatoTomato
RGBrgb(255,0,0)RGB Red
RGBArgba(255,0,0,0.5)RGBA Red
HEX#FF0000HEX Red
HSLhsl(0,100%,50%)HSL Red
HSLAhsla(0,100%,50%,0.5)HSLA Red

Background, Text and Border Color

  1. Background Color

    <p style="background-color:Tomato;">Hello</p>

    Hello

  2. Text Color

    <p style="color:blue;">Hello</p>

    Hello

  3. Border Color

    <p style="border:2px solid red;">Hello</p>

    Hello

RGB Color Model

  1. RGB = Red + Green + Blue

    rgb(red, green, blue)

  2. RGB values

    ColorRGB ValueOutput
    Redrgb(255,0,0)Red
    Greenrgb(0,255,0)Green
    Bluergb(0,0,255)Blue
    Blackrgb(0,0,0)Black
    Whitergb(255,255,255)White
    Grayrgb(120,120,120)Gray

RGBA

  1. RGBA = RGB + Alpha

    rgba(255,0,0,0.5)

    RGBA Example (50% Transparent)

  2. Alpha values

    AlphaMeaning
    0Transparent
    0.550% Visible
    1Fully Visible

HEX Colors

  1. Format

    #RRGGBB

  2. HEX codes

    ColorHEX CodeOutput
    Red#FF0000Red
    Green#00FF00Green
    Blue#0000FFBlue
    White#FFFFFFWhite
    Black#000000Black

HSL

  1. HSL = Hue + Saturation + Lightness

    hsl(0,100%,50%)

    HSL Example

  2. Properties

    PropertyDescription
    Hue0° = Red, 120° = Green, 240° = Blue
    Saturation100% = Pure Color, 0% = Gray
    Lightness0% = Black, 50% = Normal, 100% = White

HSLA

  1. HSLA = HSL + Alpha

    hsla(0,100%,50%,0.5)

    HSLA Example (Transparent)
