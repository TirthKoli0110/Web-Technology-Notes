Internet

The Internet is a worldwide network of interconnected computers and devices.

Features

  1. Worldwide connection

    Connects millions of computers worldwide.

  2. Data transfer and communication

    Allows data transfer and communication.

  3. Provides services

    Email, file transfer, remote login and web browsing (see the next section).

  4. TCP/IP protocols

    Uses TCP/IP protocols for communication.

  5. Decentralized

    It is decentralized, meaning there is no single central authority controlling the entire Internet.

  6. ISPs

    Internet connectivity is provided by ISPs (Internet Service Providers).

Services

  1. Email

    Sending and receiving messages electronically.

  2. File Transfer

    Moving files from one computer to another.

  3. Remote login

    Logging in to and using a computer from a distance.

  4. Web browsing

    Viewing web pages using a browser.

In simple words

  1. Remember this

    Internet = Network of networks
