Web Technology

Quick revision: the key terms of Unit 1, each in one line.

Key terms

  1. WWW

    Collection of interconnected webpages accessed through the Internet.

  2. Internet

    Global network of connected computers/devices.

  3. URL

    Address of a webpage.

  4. HTTP

    Protocol used for communication between browser and server.

  5. HTML

    Language used to structure webpages.

  6. Browser

    Client that requests and displays webpages.

  7. Web Server

    Receives requests and provides web resources.

  8. Web 2.0

    Interactive, social and user-generated Web.

  9. Static IP

    Fixed IP address.

  10. Dynamic IP

    Automatically assigned IP that may change.

  11. Effective Web Design

    Simple + Fast + Easy to navigate + User-focused.
