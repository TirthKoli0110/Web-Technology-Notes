Static IP Address

A Static IP address is an IP address that remains fixed for a long period and normally does not change automatically.

Uses

  1. Servers

  2. Enterprise networks

  3. VPNs

  4. Network devices that need a stable address

Example and remember

  1. Example

    192.168.1.100

  2. Remember

    Static IP = Fixed IP
