Attributes provide extra information about HTML elements. This part covers case sensitivity and the most important attributes.

15. HTML is Not Case Sensitive

  1. Uppercase Tags

    Both uppercase and lowercase tags work.

    <P>Hello</P>

  2. Lowercase Tags

    <p>Hello</p>

  3. Recommendation

    Always use lowercase HTML tags.

16. HTML Attributes

  1. Syntax

    Attributes provide extra information about HTML elements.

    <tag attribute="value">

  2. Example

    <a href="https://example.com">Visit</a>

    Output: Visit

17. Important Attributes

  1. href

    Specifies the destination of a hyperlink.

    <a href="https://example.com">Visit</a>

    Output: Visit Example

  2. src

    Specifies the location of an image.

    <img src="image.jpg">

    URL types:

    Absolute URL → Points to an external website.
    Relative URL → Points to a file within the same website.

  3. width & height

    Sets the image size.

    <img src="image.jpg" width="300" height="400">

  4. alt

    Displays alternative text if the image cannot be loaded and improves accessibility.

    <img src="image.jpg" alt="Nature">

  5. style

    Used for inline CSS.

    <p style="color:red;">Hello</p>

    Output: Hello

    Used for:

    Text Color
    Font
    Font Size
    Margin

  6. lang

    Specifies the language of the webpage.

    <html lang="en">

    Example:

    <html lang="en-US">

  7. title

    Displays a tooltip when the mouse pointer is placed over an element.

    <p title="Information">Hover me</p>

    Output: Hover your mouse over this text.
