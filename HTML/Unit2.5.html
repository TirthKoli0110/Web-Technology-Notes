HTML Text Formatting

Web Technology  /  HTML  /  Text Formatting

Text formatting tags change how text looks and what it means. This page covers subscript, superscript and the other common formatting tags.

1. <sub> - Subscript

  1. Purpose

    Displays text below the normal line.

  2. Syntax

    H<sub>2</sub>O

  3. Output

    H2O

  4. Uses

    Chemical formulas (H2O, CO2)
    Mathematical notation

  5. Remember

    Sub = Down ⬇️

2. <sup> - Superscript

  1. Purpose

    Displays text above the normal line.

  2. Syntax

    x<sup>2</sup>

  3. Output

    x2

  4. Uses

    Powers (x2)
    Footnotes
    Ordinal numbers (1st, 2nd)

  5. Remember

    Sup = Up ⬆️

3. Text Formatting Tags

Tag Purpose Example Output

<small> Smaller text Small Text
