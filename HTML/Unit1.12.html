Dynamic IP Address

A Dynamic IP address is assigned automatically and can change over time. It is commonly assigned using DHCP (Dynamic Host Configuration Protocol).

Features

  1. Automatically assigned

    The address is given to the device without manual setup.

  2. Can change periodically

    The address may be different each time the device connects.

  3. Useful for normal devices

    Good for normal devices and temporary connections.

  4. Efficient use of addresses

    Helps efficient use of available IP addresses.

Example and remember

  1. Example

    192.168.0.101
    192.168.0.102

  2. Remember

    Dynamic IP = Automatically assigned + may change
