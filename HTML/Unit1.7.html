Web Browser

A web browser is software used to access and display webpages on the Internet.

Examples

  1. Google Chrome

  2. Mozilla Firefox

  3. Safari

  4. Microsoft Edge

Functions

  1. Sends requests

    Sends requests to web servers.

  2. Receives responses

    Receives HTTP responses.

  3. Displays webpages

    Shows the received content as a webpage.

  4. User interface

    Provides an interface between the user and the web server.

  5. Stores information

    Stores information such as cookies locally.

  6. Access to online services

    Allows users to access websites and online services.

Important

  1. Remember this

    Browser = Client
