CSS Positioning

Web Technology  /  CSS  /  Lesson 11

The CSS position property determines how an element is positioned in a document. CSS has five commonly used positioning values.

1. Five Positioning Types

  1. Position values

    ValueBehavior
    staticDefault positioning in normal document flow.
    relativeRemains in normal flow but can be visually moved.
    absoluteRemoved from normal flow and positioned relative to its containing block.
    fixedUsually positioned relative to the viewport.
    stickyBehaves relatively until a scrolling threshold is reached.

2. Static Positioning

  1. Example

    .box {
    position: static;
}

  2. Key points

    • This is the default position.
    • The element follows normal document flow.
    • top and left do not reposition a static element.

  3. Static demo

    Static Box

3. Relative Positioning

  1. Example

    .box {
    position: relative;
    top: 10px;
    left: 20px;
}

  2. Key points

    • The element moves relative to its normal position.
    • Its original space remains reserved.
    • It can establish a containing block for absolute descendants.

  3. Relative demo

    Relative Box

    Offset: top 0px, left 0px

4. Absolute Positioning

  1. Example

    .parent {
    position: relative;
}

.child {
    position: absolute;
    top: 10px;
    right: 10px;
}

  2. Key points

    • The child is removed from normal document flow.
    • It is positioned relative to its containing block.
    • A relatively positioned parent can act as its containing block.

    Absolute positioning is useful for badges, labels and icons inside cards.

5. Fixed Positioning

  1. Example

    .button {
    position: fixed;
    bottom: 20px;
    right: 20px;
}

  2. Definition

    Fixed positioning usually places an element relative to the viewport. It remains in place while the page scrolls.

  3. Common uses

    • Floating buttons.
    • Persistent interface controls.
    • Fixed navigation elements.

  4. Fixed demo

6. Sticky Positioning

  1. Example

    header {
    position: sticky;
    top: 0;
}

  2. Definition

    A sticky element scrolls normally until it reaches a specified scrolling threshold. It then stays stuck within its scrolling container while conditions allow.

  3. Common uses

    • Sticky navigation bars.
    • Table headers.
    • Section headings.

7. Positioning Comparison

  1. Comparison

    ValueSpace Retained?Common Use
    staticYesRegular content
    relativeYesSmall offsets and positioning anchors
    absoluteNoOverlays and positioned children
    fixedNoFloating interface elements
    stickyGenerally yesSticky headers
