CSS Practice Examples

Web Technology  /  CSS  /  Lesson 15

In this lesson, we will practise four important CSS examples used in real-world websites: a styled paragraph, a card, a navigation bar and a responsive grid.

1. Example: Styling a Paragraph

  1. CSS code

    p {
    color: navy;
    font-size: 16px;
    line-height: 1.6;
}

  2. Explanation

    PropertyWhat it does
    colorChanges the text colour.
    font-sizeSets the text size.
    line-heightControls the space between lines.

  3. Live result

    This is an example paragraph styled with navy text, a 16px font size and increased line spacing. CSS makes text easier to read and improves the appearance of a webpage.

    Result: The paragraph appears in navy with increased line spacing.

2. Example: Styling a Card

  1. CSS code

    .card {
    background-color: white;
    padding: 20px;
    border: 1px solid gray;
    border-radius: 10px;
    box-shadow: 0 4px 8px rgba(0, 0, 0, 0.1);
}

  2. Explanation

    PropertyWhat it does
    background-colorSets the card background.
    paddingAdds internal spacing.
    borderAdds an outline.
    border-radiusRounds the corners.
    box-shadowAdds a shadow effect.

  3. Live result

    My Sample Card

    This card demonstrates background colour, padding, border, rounded corners and shadow.

    Result: A white card with spacing, a border, rounded corners and shadow.

3. Example: Creating a Navigation Bar

  1. CSS code

    nav {
    display: flex;
    justify-content: space-around;
    align-items: center;
    background-color: navy;
    padding: 15px;
}

nav a {
    color: white;
    text-decoration: none;
}

  2. Explanation

    PropertyWhat it does
    display: flexArranges navigation items using Flexbox.
    justify-contentDistributes the links horizontally.
    align-itemsAligns items vertically.
    background-colorSets the navigation background.
    text-decorationRemoves the default underline.

  3. Live result

    Home About Services Contact

    Result: Navigation links are arranged using Flexbox on a navy background.

4. Example: Creating a Responsive Grid

  1. CSS code

    .container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 15px;
}

@media (max-width: 600px) {
    .container {
        grid-template-columns: 1fr;
    }
}

  2. Explanation

    CodeWhat it does
    display: gridCreates a grid layout.
    grid-template-columnsDefines the columns.
    repeat(3, 1fr)Creates three equal columns.
    gapAdds space between grid items.
    media queryChanges the layout on narrow screens.

  3. Live result

    Choose a screen size to see the layout change:

    Result: Three columns on wider screens and one column at 600px or less.
