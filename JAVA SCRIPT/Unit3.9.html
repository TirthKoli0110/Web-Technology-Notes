CSS Borders

Web Technology  /  CSS  /  Lesson 9

A border is a line surrounding an element's padding and content. CSS allows us to control its thickness, style, color and corners.

1. Border Properties

  1. Properties

    PropertyPurpose
    border-widthControls border thickness.
    border-styleControls the border pattern.
    border-colorControls border color.
    border-radiusRounds the corners of an element.

2. Common Border Styles

  1. Style values

    StyleAppearance
    solidContinuous line
    dottedDotted line
    dashedDashed line
    doubleTwo lines
    noneNo border

3. Border Shorthand Property

  1. Definition

    The border shorthand allows us to set width, style and color in one declaration.

  2. Example

    .box {
    border: 2px solid navy;
}

    This creates a 2-pixel solid navy border.

  3. General syntax

    border: width style color;

  4. Border width demo

    Change my border thickness!

    Current width: 3px

4. Border Color

  1. Definition

    The border-color property controls the color of an element's border.

  2. Example

    .box {
    border: 3px solid navy;
}

  3. Border color demo

    Change my border color!

    Current color: blue

5. Individual Borders

  1. Definition

    CSS allows us to style each side of an element separately.

  2. Side properties

    PropertyStyles
    border-topTop side
    border-rightRight side
    border-bottomBottom side
    border-leftLeft side

  3. Example

    .box {
    border-top: 2px solid red;
    border-right: 3px dashed blue;
    border-bottom: 2px solid green;
    border-left: 4px dotted orange;
}

  4. Individual border demo

    Each side has a different border style and color.

6. Rounded Corners

  1. Definition

    The border-radius property rounds the corners of an element.

  2. Example

    .box {
    border: 2px solid navy;
    border-radius: 10px;
}

  3. Radius values

    ValueResult
    0pxSharp corners
    10px, 25pxSoftly rounded corners
    50%Circle or oval shape
