Colors and Backgrounds

Web Technology  /  CSS  /  Lesson 7

This page covers color formats, RGBA transparency, background properties, repeat and size values, gradients and text contrast.

1. Ways to Specify Colors

  1. Color formats

    FormatExampleExplanation
    Named ColortomatoUses a predefined color name.
    Hexadecimal#FF6347Uses hexadecimal digits.
    RGBrgb(255, 99, 71)Uses red, green and blue values.
    RGBArgba(255, 99, 71, 0.5)RGB with transparency.
    HSLhsl(9, 100%, 64%)Uses hue, saturation and lightness.

  2. Color example

    h1 {
    color: tomato;
    background-color: lightyellow;
}

  3. color vs background-color

    colorbackground-color
    Changes text colorChanges background color

2. Transparency Using RGBA

  1. Definition

    RGBA adds an alpha value to RGB. The alpha value controls transparency.

  2. Example

    .box {
    background-color: rgba(255, 99, 71, 0.5);
}

  3. Alpha values

    AlphaMeaning
    1Fully visible (100%)
    0.5Half transparent (50%)
    0Fully transparent (0%)

3. Background Properties

  1. Properties

    PropertyPurpose
    background-colorSets a solid background color
    background-imageAdds images or gradients
    background-repeatControls image repetition
    background-positionSets the image position
    background-sizeControls image dimensions
    background-attachmentControls background behavior while scrolling

  2. Background example

    .banner {
    background-color: #174678;
    background-image: linear-gradient(
        100deg, #174678, #31765b
    );
    background-repeat: no-repeat;
    background-position: center;
    background-size: cover;
}

4. Background Repeat Values

  1. Repeat values

    ValuePurpose
    repeatRepeats horizontally and vertically
    repeat-xRepeats horizontally
    repeat-yRepeats vertically
    no-repeatDisplays the image once

6. CSS Gradients

  1. Definition

    Gradients create smooth color transitions without requiring a separate image file.

  2. Example

    .banner {
    background-image: linear-gradient(
        to right, blue, green
    );
}
