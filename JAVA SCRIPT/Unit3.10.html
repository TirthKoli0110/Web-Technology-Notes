The CSS Box Model

Web Technology  /  CSS  /  Lesson 10

The CSS Box Model explains how the size of an HTML element is calculated. Every HTML element is represented by a rectangular box consisting of four layers.

1. Four Layers of the Box Model

  1. Layers (inside to outside)

    LayerMeaning
    ContentText, images or other material inside an element.
    PaddingSpace between content and border.
    BorderLine surrounding padding and content.
    MarginSpace outside the border.

3. Content-Box Sizing

  1. Default value

    box-sizing: content-box;

    In content-box, the declared width and height apply only to the content. Padding and borders increase the final dimensions.

  2. Example

    .box {
    width: 300px;
    padding: 20px;
    border: 5px solid black;
}

  3. Width calculation

    PartCalculationWidth
    ContentDeclared width300px
    Left + right padding20px × 240px
    Left + right borders5px × 210px
    Total width300 + 40 + 10350px

    Margins are outside the border and add further spacing around the element.

4. Border-Box Sizing

  1. Definition

    With border-box, the declared width includes content, padding and border.

  2. Example

    .box {
    box-sizing: border-box;
    width: 300px;
    padding: 20px;
    border: 5px solid black;
}

  3. Width calculation

    PartCalculationWidth
    Total widthDeclared width300px
    Padding20px × 240px
    Border5px × 210px
    Content width300 − 40 − 10250px

6. Recommended Global Rule

  1. Rule

    *,
*::before,
*::after {
    box-sizing: border-box;
}

    This rule makes element sizing easier to predict because padding and borders are included in declared dimensions.

7. Margin vs Padding

  1. Difference

    MarginPadding
    Space outside the border.Space inside the border.
    Separates neighboring elements.Separates content from its border.
    Background does not fill the margin.Background generally extends through padding.

9. Important Additional Point

  1. Margin collapsing

    In normal block layout, adjacent vertical margins can collapse rather than simply add together. This behavior is called margin collapsing.
