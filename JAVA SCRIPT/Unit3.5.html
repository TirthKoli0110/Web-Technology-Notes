How the CSS Cascade Chooses a Value

Web Technology  /  CSS  /  The Cascade

The CSS cascade is the process through which the browser determines which CSS declaration applies when multiple rules target the same property.

Example of CSS Cascade

  1. CSS code

    p {
  color: black;
}

.notice {
  color: blue;
}

#warning {
  color: red;
}

  2. HTML code

    <p id="warning" class="notice">
  Read carefully.
</p>

  3. Explanation

    The paragraph appears red because the ID selector has greater specificity than the class and element selectors.

5.1 Factors Affecting the Cascade

  1. Origin and Importance

    Determines where a declaration comes from and whether it is marked with !important.

  2. Specificity

    Determines how specifically a selector identifies an HTML element.

  3. Scoping Proximity

    Relevant when scoped styles are involved. The browser considers how close a scoped rule is to the element.

  4. Source Order

    When competing declarations remain tied, the later declaration generally wins.

5.2 Basic Specificity Order

Remember:
Inline styles generally outrank normal stylesheet declarations, but !important declarations and other cascade rules can change the outcome.

5.3 Understanding !important

  1. What it does

    The !important annotation changes the priority of a CSS declaration. It gives the declaration higher priority within the cascade.

  2. Example

    p {
  color: blue !important;
}

  3. Disadvantages of !important

    • It can make styles harder to override.
    • It can make code difficult to maintain.
    • It should be used sparingly.

Important Points to Remember

  • The cascade decides which CSS declaration applies.
  • Specificity determines selector priority.
  • An ID selector is more specific than a class selector.
  • A class selector is more specific than an element selector.
  • Source order matters when other factors are tied.
  • Inline styles generally outrank normal stylesheet rules.
  • !important changes declaration priority.
  • Use !important sparingly.
