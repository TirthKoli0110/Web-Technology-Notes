CSS3 and Modern CSS Features

Web Technology  /  CSS  /  Lesson 12

CSS has evolved through separate modules rather than a single all-encompassing CSS3 or CSS4 release. Modern CSS includes features for responsive design, layouts, animations and visual effects.

1. Modern CSS Features

  1. Feature list

    FeaturePurpose
    FlexboxCreates flexible layouts.
    CSS GridCreates rows and columns.
    Media QueriesMake websites responsive.
    GradientsCreate smooth color transitions.
    Rounded CornersRound element corners.
    Box ShadowsAdd shadows to elements.
    TransformsChange visual appearance.
    TransitionsMake changes happen smoothly.

2. Rounded Corners

  1. Definition

    The border-radius property rounds the corners of an element.

  2. Example

    .card {
    border-radius: 12px;
}

    Rounded Card

3. Box Shadow

  1. Definition

    The box-shadow property adds a shadow around an element. It creates a sense of depth.

  2. Example

    .card {
    box-shadow: 0 4px 10px rgba(0, 0, 0, 0.2);
}

  3. Interactive shadow demo

    Shadow Card

    Box shadows make elements appear elevated.

    Current shadow: Small shadow

4. Linear Gradient

  1. Definition

    The linear-gradient() function creates a gradual transition between colors.

  2. Example

    .banner {
    background: linear-gradient(to right, blue, green);
}

    This creates a horizontal blue-to-green gradient.

  3. Interactive gradient demo

    Beautiful Gradient

    Modern CSS creates attractive backgrounds.

5. Transform

  1. Definition

    The transform property changes an element's visual position, rotation, scale or shape.

  2. Example

    .card:hover {
    transform: scale(1.05);
}

    When the pointer hovers over the card, it visually enlarges to 105% of its original size.

  3. Transform functions

    FunctionEffect
    scale(1.2)Makes the element larger or smaller
    rotate(10deg)Turns the element
    translateX(30px)Moves the element sideways
    skewX(10deg)Slants the element

  4. Interactive transform demo

    Transform Card

6. Transition

  1. Definition

    The transition property makes changes to supported CSS properties happen gradually.

  2. Example

    .card {
    transition: transform 0.3s ease;
}

    When combined with the hover transform rule, the scaling effect becomes smoother.

    Click the buttons to see the difference between an instant change and a gradual change.

7. Difference Between Transform and Transition

  1. Difference

    TransformTransition
    Changes visual appearance.Controls how changes happen over time.
    Can rotate, scale and move elements.Makes supported property changes gradual.
    Example: scale(1.05)Example: 0.3s ease
