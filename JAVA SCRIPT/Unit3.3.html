CSS Syntax and Selectors

Web Technology  /  CSS  /  Syntax and Selectors

CSS selectors determine which HTML elements receive styling. CSS syntax defines how styling rules are written.

3.1 CSS Syntax

  1. What a rule is

    A CSS rule consists of a selector and a declaration block.

  2. General syntax

    selector {
  property: value;
}

  3. Example

    .notice {
  color: blue;
  background-color: lightgray;
  border-left: 4px solid blue;
  padding: 10px;
}

  4. Components of a CSS rule

    Selector: Identifies the HTML elements to style.
    Property: Specifies what aspect of an element to change.
    Value: Specifies the setting for that property.
    Declaration: A property and its value.
    Declaration Block: All declarations enclosed in curly braces { }.

  5. Understanding the example

    Selector: .notice
    Property: color
    Value: blue
    Declaration: color: blue;

  6. Note

    A semicolon separates declarations, and curly braces enclose the declaration block.

3.3 Examples of CSS Selectors

  1. Element Selector

    p {
  line-height: 1.6;
}

    Applies line height to all paragraph elements.

  2. Class Selector

    .notice {
  padding: 10px;
}

    Applies padding to every element with class="notice".

    HTML:

    <p class="notice">
  Important information.
</p>

  3. ID Selector

    #main-title {
  color: navy;
}

    Styles the element whose ID is main-title.

    HTML:

    <h1 id="main-title">Welcome</h1>

  4. Universal Selector

    * {
  box-sizing: border-box;
}

    Applies the specified sizing rule to all elements.

  5. Grouping Selector

    h1, h2 {
  color: navy;
}

    Applies the same color to both heading types.

  6. Descendant Selector

    nav a {
  text-decoration: none;
}

    Removes text decoration from links anywhere inside a navigation element.

  7. Child Selector

    ul > li {
  margin-bottom: 5px;
}

    Applies margin only to list items that are direct children of a ul element.

  8. Pseudo-class

    a:hover {
  color: green;
}

    Changes a link's color when the pointer hovers over it.

  9. Pseudo-element

    p::first-line {
  font-weight: bold;
}

    Makes the first formatted line of each paragraph bold.

  10. Attribute Selector

    input[type="email"] {
  border-color: blue;
}

    Styles input elements whose type is email.

3.4 Important Distinction

  1. Class Selector

    A class can be used on multiple HTML elements.

    <p class="notice">First paragraph</p>
<p class="notice">Second paragraph</p>

  2. ID Selector

    An ID should uniquely identify one element within an HTML document.

    <h1 id="main-title">Welcome</h1>

Important Points to Remember

  1. Remember

    CSS rules contain selectors and declaration blocks.
    A property defines what to change.
    A value defines how the property should appear.
    A class selector uses a dot (.).
    An ID selector uses a hash (#).
    A universal selector uses an asterisk (*).
    A class can be reused on multiple elements.
    An ID should be unique within an HTML document.
