Popup Boxes in JavaScript

Web Technology  /  Unit 4  /  Topic 7

JavaScript provides three basic browser dialog functions for interacting with users.

Types of Popup Boxes

MethodPurposeReturn Value
alert()Displays a message.No meaningful value.
confirm()Asks for confirmation.true for OK, false for Cancel.
prompt()Requests text input.Entered string or null if cancelled.

Example

  1. Code

    function showPopups() {
    alert("Welcome to Unit 4!");

    const proceed = confirm("Do you want to continue?");

    if (proceed) {
        result.textContent = "Continuing";
    } else {
        result.textContent = "Cancelled";
    }

    const name = prompt("What is your name?");

    if (name !== null) {
        result.textContent += " - Welcome, " + name;
    }
}

  2. Try it

    Click the button. Three popups will appear one after another.

Explanation

  1. alert()

    Informs the user.

  2. confirm()

    Collects a yes/no decision.

  3. prompt()

    Accepts a short text response.

These dialogs are useful for simple demonstrations. Modern websites often use custom-designed interfaces for a better user experience.
