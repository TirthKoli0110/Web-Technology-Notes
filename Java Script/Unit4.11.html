Events and Buttons in JavaScript

Web Technology  /  Unit 4  /  Topic 8

An event is an action or occurrence in the browser, such as a button click, key press, form submission or page load.

An event listener connects an event to a function that runs when the event occurs.

Common JavaScript Events

EventMeaningCommon Use
clickUser clicks or activates an element.Button actions
inputUser changes an input value.Live validation
submitUser submits a form.Form validation
keydownUser presses a key.Keyboard shortcuts
loadA resource or page finishes loading.Initialization

Example: Button Click Counter

  1. HTML code

    <button id="button">Click Me</button>

<h3>Count: <span id="output">0</span></h3>

  2. JavaScript code

    let count = 0;

const button = document.getElementById("button");
const output = document.getElementById("output");

button.addEventListener("click", (event) => {

    count++;

    output.textContent = count;

});

  3. Try it

    Click the button to increase the counter.

    Count: 0

Explanation

  • addEventListener() registers an event listener.
  • "click" specifies the event to detect.
  • The callback function runs when the event occurs.
  • count++ increases the counter by one.
  • output.textContent displays the updated count.
  • event contains information about the event.

Why Use addEventListener()?

It separates JavaScript behaviour from HTML structure and allows multiple listeners to be attached to an element.

A button can respond to clicks without placing JavaScript directly inside its HTML markup.
