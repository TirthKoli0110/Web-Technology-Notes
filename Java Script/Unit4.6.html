Functions in JavaScript

Web Technology  /  Unit 4  /  Topic 6

A function is a reusable block of code that performs a specific task. It reduces repetition and makes programs easier to understand and maintain.

Syntax

function functionName(parameters) {
    // Statements
    return value;
}

  1. Function name

    Identifies the function.

  2. Parameters

    Inputs received by the function.

  3. Return

    Sends a result back to the calling code.

Example 1: Function with Parameters

  1. Code

    function calculateTotal(price, quantity) {
    return price * quantity;
}

const bill = calculateTotal(120, 3);

console.log("Total Bill: " + bill);

  2. Live output

Here, price and quantity are parameters, while 120 and 3 are arguments.

Example 2: Function Returning a Greeting

  1. Code

    function greet(student) {
    return "Welcome, " + student + "!";
}

console.log(greet("Asha"));

  2. Live output
