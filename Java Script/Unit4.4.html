Conditions and Logical Operators

Web Technology  /  Unit 4  /  Topic 4

Conditions allow a program to make decisions based on whether an expression is true or false.

Conditional Statements

  1. if

    Executes code when a condition is true.

  2. else if

    Checks another condition when the previous condition is false.

  3. else

    Executes when none of the conditions is true.

Example

  1. Code

    const age = 20;
const feesPaid = true;

if (age >= 18 && feesPaid) {
    console.log("Student can register");
} else if (age >= 18 && !feesPaid) {
    console.log("Please pay the fees");
} else {
    console.log("Student is not eligible");
}

Logical Operators

  1. The three logical operators

    OperatorMeaningExample
    &&AND - Both conditions must be true.age >= 18 && feesPaid
    ||OR - At least one condition must be true.isAdmin || isTeacher
    !NOT - Reverses a Boolean value.!feesPaid

Ternary Operator

The ternary operator is a short form of if...else.

  1. Example code

    const age = 20;
const result = age >= 18 ? "Adult" : "Minor";

console.log("Result: " + result);
