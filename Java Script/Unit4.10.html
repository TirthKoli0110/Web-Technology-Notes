DHTML: HTML, CSS and JavaScript Together

Web Technology  /  Unit 4  /  Topic 10

DHTML (Dynamic HTML) is a descriptive term for using HTML, CSS and JavaScript together to make webpages interactive and dynamically change their appearance or content.

It is not a separate programming language.

Roles of Three Technologies

TechnologyRoleWhat it does
1. HTMLStructureCreates headings, forms, cards, buttons and other page elements.
2. CSSPresentationControls layout, colours, spacing and visual states.
3. JavaScriptBehaviourResponds to events and changes DOM content, attributes or classes.

How DHTML Works

  1. Step 1

    The browser reads HTML and creates the DOM tree.

  2. Step 2

    CSS rules determine how the elements appear.

  3. Step 3

    JavaScript selects elements and listens for events.

  4. Step 4

    When an event occurs, JavaScript updates the DOM.

  5. Step 5

    The browser applies CSS and redraws the affected content.

Example: Interactive Course Card

  1. HTML code

    <div id="dhtml-card">

    <h3>Interactive Course Card</h3>

    <p>Press the button to highlight this card.</p>

</div>

<button id="dhtml-toggle">Toggle Highlight</button>

  2. JavaScript code

    const card = document.querySelector("#dhtml-card");

const toggleButton =
    document.querySelector("#dhtml-toggle");

let isActive = false;

toggleButton.addEventListener("click", () => {

    if (isActive) {
        card.style.backgroundColor = "white";
        card.style.color = "black";
        isActive = false;
    } else {
        card.style.backgroundColor = "teal";
        card.style.color = "white";
        isActive = true;
    }

});

  3. Try it

    Interactive Course Card

    Press the button to highlight this card.

Explanation

Clicking the button changes the card's background colour and text colour using JavaScript. This demonstrates dynamic webpage behaviour.
