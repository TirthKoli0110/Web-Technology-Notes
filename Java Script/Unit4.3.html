JavaScript Data Types

Web Technology  /  Unit 4  /  Topic 3

A data type describes the kind of value a variable contains. JavaScript is dynamically typed, meaning a variable can hold values of different types at different times.

Types of Data Types

  1. The eight data types

    Data TypeExampleMeaning
    String"Hello"Text
    Number42, 3.14Integers and decimal values
    BigInt9007199254740993nVery large integers
    Booleantrue, falseLogical values
    UndefinedundefinedA value has not been assigned
    NullnullIntentional absence of a value
    SymbolSymbol("id")Unique identifier
    Object{name: "Asha"}Collection of properties

Arrays and functions are also object-related types in JavaScript.

Checking Data Types

Use the typeof operator to determine the type of a value.

  1. Example code

    const name = "Asha";
const marks = 85;
const isEnrolled = true;

console.log("Name: " + typeof name);
console.log("Marks: " + typeof marks);
console.log("Is Enrolled: " + typeof isEnrolled);

  2. Live output

Important Facts

  1. Example code

    console.log("typeof undefined: " + typeof undefined);
console.log("typeof null: " + typeof null);
console.log("typeof []: " + typeof []);
console.log("Array.isArray([]): " + Array.isArray([]));
console.log("typeof function: " + typeof function() {});

  2. Live output

Remember: typeof null gives "object". This is a well-known quirk of JavaScript, so check for null with value === null, and use Array.isArray() to check for arrays.
