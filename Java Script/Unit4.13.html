Synchronous vs Asynchronous Operations

Web Technology  /  Unit 4  /  Topic 11

Synchronous operation: The next step waits for the current operation to finish before continuing.

Asynchronous operation: A time-consuming operation, such as a network request, can finish later while JavaScript continues responding to other events.

Important Terms

TermExplanation
fetch()Sends an HTTP request and returns a Promise.
PromiseRepresents an operation that may complete successfully or fail later.
ResponseRepresents the HTTP response received from the server.
asyncDeclares a function that returns a Promise.
awaitWaits for a Promise to settle inside an async function.

Example 1: Synchronous Operation

  1. HTML code

    <button onclick="syncExample()">Run Synchronous</button>

<p id="syncResult"></p>

  2. JavaScript code

    function syncExample() {

    let result = "";

    result += "Step 1: Start\n";
    result += "Step 2: Processing\n";
    result += "Step 3: Finish\n";

    document.getElementById("syncResult").textContent = result;
}

  3. Try it

    All three steps run one after another, in order.

Example 2: Asynchronous Operation

  1. HTML code

    <button onclick="asyncExample()">Run Asynchronous</button>

<p id="asyncResult"></p>

  2. JavaScript code

    function asyncExample() {

    const output = document.getElementById("asyncResult");

    output.textContent = "Step 1: Start\n";

    setTimeout(function () {

        output.textContent += "Step 2: Delayed operation completed\n";

    }, 2000);

    output.textContent += "Step 3: Continue without waiting\n";
}

  3. Try it

    Step 3 appears first. Step 2 appears two seconds later, because JavaScript does not wait for the timer.

Example 3: Fetch Data from a Server

  1. HTML code

    <button onclick="loadData()">Load Data</button>

<p id="dataResult"></p>

  2. JavaScript code

    async function loadData() {

    const output = document.getElementById("dataResult");

    output.textContent = "Loading data...";

    try {

        const response = await fetch(
            "https://jsonplaceholder.typicode.com/posts/1"
        );

        if (!response.ok) {
            throw new Error("Request failed");
        }

        const data = await response.json();

        output.textContent =
            "Title: " + data.title +
            "\n\nBody: " + data.body;

    } catch (error) {

        output.textContent = "Error: " + error.message;

    }
}

  3. Try it

    Click the button to load a sample post from a test server. This needs an internet connection.

Explanation

  1. fetch()

    Sends a request to the specified URL.

  2. await

    Waits for the response Promise to settle.

  3. response.ok

    Checks whether the HTTP status indicates success.

  4. response.json()

    Reads and parses the response body as JSON.

  5. catch

    Handles network failures and other errors.

Important

fetch() does not automatically reject its Promise for HTTP error statuses such as 404 or 500. Check response.ok to handle those cases.

Asynchronous operations help keep webpages responsive while waiting for server responses. They do not mean that every JavaScript instruction runs in parallel.
