Loops in JavaScript

Web Technology  /  Unit 4  /  Topic 5

Loops execute a block of code repeatedly. They are useful for processing lists, printing results and repeating calculations.

for Loop

Used when you need to repeat instructions, often with a counter.

  1. Example code

    for (let i = 1; i <= 3; i++) {
    console.log(i);
}

  2. Live output

while Loop

Repeats as long as the condition remains true.

  1. Example code

    let count = 1;

while (count <= 3) {
    console.log(count);
    count++;
}

  2. Live output

for...of Loop

Used to visit each value in an iterable, such as an array.

  1. Example code

    const subjects = ["HTML", "CSS", "JavaScript"];

for (const subject of subjects) {
    console.log(subject);
}

  2. Live output

Difference Between Loops

  1. Which loop to use

    LoopMain Use
    forRepetition with initialization, condition and update.
    whileRepetition while a condition is true.
    for...ofIterating over values in an array or another iterable.

Important

Update the loop variable where necessary to prevent an infinite loop.
