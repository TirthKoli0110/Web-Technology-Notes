Client-Side Scripting with JavaScript

Web Technology  /  JavaScript  /  Introduction

JavaScript is a high-level, dynamic programming language that makes web pages interactive.

1. Role of HTML, CSS and JavaScript

  1. Three technologies, three jobs

    TechnologyRole
    HTMLDefines the structure and content of a webpage.
    CSSControls the appearance and design of a webpage.
    JavaScriptAdds behaviour and interactivity.

2. Fundamental Building Blocks

  1. Building blocks

    BlockPurpose
    VariablesStore information.
    ConditionsMake decisions.
    LoopsRepeat instructions.
    FunctionsGroup reusable instructions.
    Objects and ArraysOrganize related data.
    Browser APIsInteract with webpages and browsers.

3. JavaScript Example

  1. Code

    <button onclick="showMessage()">Click Me</button>
<p id="message"></p>

<script>
    function showMessage() {
        document.getElementById("message").innerHTML =
            "Welcome to JavaScript!";
    }
</script>

  2. Explanation

    PartWhat it does
    onclickRuns the function when the button is clicked.
    showMessage()A function that groups the instructions to run.
    getElementByIdFinds the element with the matching id on the page.
    innerHTMLSets the content shown inside that element.
