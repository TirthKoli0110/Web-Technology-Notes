Forms and Validation

Web Technology  /  Unit 4  /  Topic 9

Form validation is the process of checking user input before accepting or submitting it.

Examples of Form Validation

  • Checking whether required fields are filled in.
  • Checking whether an email address has a valid format.
  • Checking whether a password meets the minimum length.
  • Checking whether a number falls within an allowed range.
  • Checking whether input follows a specified pattern.

A. HTML Validation Attributes

AttributePurposeExample
requiredMakes a field compulsory.<input required>
typeSpecifies the input type.type="email"
minlengthSets minimum text length.minlength="2"
maxlengthSets maximum text length.maxlength="40"
minSets minimum numeric value.min="1"
maxSets maximum numeric value.max="10"
stepSets permitted increments.step="1"
patternRequires a matching pattern.pattern="[A-Z]{2}[0-9]{4}"

B. JavaScript Validation Methods

MethodPurpose
checkValidity()Checks whether input satisfies validation rules.
reportValidity()Displays validation feedback.
setCustomValidity(message)Defines a custom error message.
setCustomValidity("")Clears a custom error message.

C. Form Validation Example

  1. HTML code

    <form id="myForm" novalidate>
    <label for="name">Student Name:</label>
    <input type="text" id="name" required minlength="2">

    <label for="email">Email:</label>
    <input type="email" id="email" required>

    <label for="password">Password:</label>
    <input type="password" id="password" required minlength="6">

    <label for="age">Age:</label>
    <input type="number" id="age" min="1" max="100" required>

    <button type="submit">Submit</button>
    <button type="reset">Reset</button>
</form>

  2. JavaScript code

    
// The Reset button clears the fields and the message
form.addEventListener("reset", () => {
    message.textContent = "";
});

  3. Try it

    Fill in the form, or leave fields empty, and click Submit. After a successful submit the form clears itself. Click Reset at any time to clear the fields and the message. The novalidate attribute stops the browser from checking on its own, so the JavaScript above does the checking.

D. Validation Process

  1. Step 1

    Collect the user's input.

  2. Step 2

    Check built-in HTML constraints.

  3. Step 3

    Apply additional application-specific rules.

  4. Step 4

    Display errors and guide the user to correct them.

  5. Step 5

    Submit the data only after validation succeeds.

  6. Step 6

    Validate the data again on the server.

Important Exam Point

Client-side validation improves user experience, but it is not a security measure by itself. Server-side validation is also necessary because client-side JavaScript can be disabled or bypassed.
