Variables and Values

Web Technology  /  Unit 4  /  Topic 2

A variable is a named storage location used to hold data.

Example

  1. Code

    const studentName = "Asha";
let marks = 78;
let isPass = marks >= 40;

console.log(studentName);
console.log(marks);
console.log(isPass);

  2. Values stored

    VariableValueType of value
    studentName"Asha"Text (string)
    marks78Number
    isPasstrueTrue or false (boolean)

let vs const

  1. Difference

    KeywordMeaning
    letUsed when a variable may be reassigned.
    constUsed when a variable should not be reassigned.

Example of let and const

  1. Code

    let score = 80;
score = 90;

const course = "Web Technologies";

console.log("Score: " + score);
console.log("Course: " + course);

Remember

  1. const and objects or arrays

    A const variable cannot be reassigned, but the contents of an object or array declared with const can still be modified.

    const subjects = ["HTML", "CSS"];

subjects.push("JavaScript");   // allowed: changes the contents
subjects = ["Python"];         // error: reassigns the variable
