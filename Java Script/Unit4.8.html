Web Technology  /  Unit 4  /  Topic 8

A. Objects

An object stores related information as properties and can also contain functions called methods.

  1. Example

    const learner = {
    name: "Asha",
    unit: 4,

    introduce() {
        return `${this.name} is studying Unit ${this.unit}.`;
    }
};

console.log(learner.name);
console.log(learner.introduce());

  2. Live output

Here, name and unit are properties, and introduce() is a method. The this keyword refers to the object.

B. DOM (Document Object Model)

The DOM is a programming representation of an HTML document as a tree of nodes or objects.

  1. Uses of DOM

    • Find HTML elements.
    • Read or change text.
    • Modify attributes and CSS classes.
    • Create and remove elements.
    • Respond to user actions.

Common DOM Operations

OperationExamplePurpose
Select an elementdocument.querySelector(".notice")Finds the first matching element.
Change textelement.textContent = "Updated"Replaces text content.
Toggle a classelement.classList.toggle("active")Adds or removes a CSS class.
