AJAX and Asynchronous Web Applications

Web Technology  /  Unit 4  /  Topic 10

AJAX stands for Asynchronous JavaScript and XML.

It is a technique that allows JavaScript to send HTTP requests to a server and update part of a webpage without reloading the entire page.

Although XML appears in the name, modern AJAX applications commonly exchange JSON data.

Uses of AJAX

  • Searching a catalogue without reloading the page.
  • Refreshing messages.
  • Checking whether a username is available.
  • Updating shopping-cart totals.
  • Submitting forms and displaying responses.
  • Loading information from a server when required.

Request and Response Cycle

  1. User action

    A click or another event starts the request.

  2. Request

    JavaScript sends an HTTP request using GET or POST.

  3. Response

    The server processes the request and returns JSON or text.

  4. Update

    JavaScript updates the DOM without reloading the page.

GET and POST Methods

  • GET: Commonly used to retrieve information from a server.
  • POST: Commonly used to send data to a server for processing.

AJAX Example

  1. HTML code

    <button onclick="loadData()">Load Data</button>

<p id="result">Click the button to load information.</p>

  2. JavaScript code

    function loadData() {

    const result = document.getElementById("result");

    result.textContent = "Loading...";

    fetch("https://jsonplaceholder.typicode.com/posts/1")

        .then(response => {
            if (!response.ok) throw new Error("Request failed");
            return response.json();
        })

        .then(data => {
            result.textContent =
                "Title: " + data.title +
                "\n\nBody: " + data.body;
        })

        .catch(error => {
            result.textContent = "Error loading data.";
        });
}

  3. Try it

    Click the button to load a sample post from a test server. This needs an internet connection.

    Click the button to load information.

Explanation

  • fetch(): Sends an HTTP request to the server.
  • response.json(): Converts the response into JSON data.
  • then(): Processes the returned data.
  • textContent: Displays the received information on the webpage.
  • catch(): Handles errors if the request fails.

Remember

AJAX is a communication technique, not a server or database itself. It requires a server or API to provide the requested information.
