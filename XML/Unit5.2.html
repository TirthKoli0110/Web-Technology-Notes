Well-formed XML vs Valid XML

Web Technology  /  Unit 5  /  Topic 2

An XML document can be well-formed, and it can also be valid. These are two different levels of correctness.

A. Well-formed XML

  1. What it is

    A well-formed XML document follows all basic XML syntax rules.

  2. Rules

    • Must have exactly one root element.
    • Every opening tag must have a closing tag.
    • Tags must be properly nested.
    • Attribute values must be enclosed in quotes.
    • XML tags are case-sensitive.

B. Valid XML

  1. What it is

    A valid XML document is a well-formed document that also follows the rules defined in a DTD or XML Schema (XSD).

  2. Remember

    Well-formed = Follows XML syntax rules.

    Valid = Follows XML syntax rules + DTD or XSD rules.

Example of XML

  1. XML code

    <catalog>
    <book id="b101">
        <title>Learning XML</title>
        <author>Asha Rao</author>
        <price currency="INR">450</price>
    </book>

    <book id="b102">
        <title>Data on the Web</title>
        <author>Neil Patel</author>
        <price currency="INR">525</price>
    </book>
</catalog>

  2. Explanation

    This XML contains two book elements inside the root element catalog.

Uses of XML

  1. Data exchange

    Exchanging structured data between applications.

  2. Configuration

    Creating configuration files.

  3. Document formats

    Creating document formats and RSS feeds.

  4. Readable data

    Representing data in a readable and organized format.

JavaScript XML Validation Example

  1. HTML code

    <textarea id="xmlData" rows="10" cols="50">
&lt;catalog&gt;
    &lt;book&gt;
        &lt;title&gt;Learning XML&lt;/title&gt;
        &lt;author&gt;Asha Rao&lt;/author&gt;
    &lt;/book&gt;
&lt;/catalog&gt;
</textarea>

<button onclick="checkXML()">Check XML</button>

<p id="result"></p>

  2. JavaScript code

    function checkXML() {
    let xml = document.getElementById("xmlData").value;

    let parser = new DOMParser();
    let data = parser.parseFromString(xml, "text/xml");

    if (data.getElementsByTagName("parsererror").length > 0) {
        document.getElementById("result").textContent =
            "XML is not well-formed.";
    } else {
        document.getElementById("result").textContent =
            "XML is well-formed.";
    }
}

  3. Try it

    Click Check XML. Then break the XML, for example by deleting a closing tag, and click again. This checker tests only whether the XML is well-formed. It does not check a DTD or XSD, so it cannot tell you whether the XML is valid.
