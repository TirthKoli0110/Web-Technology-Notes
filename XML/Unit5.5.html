Transforming XML Using XSL and XSLT

Web Technology  /  Unit 5  /  Topic 4

XSL and XSLT are used to work with XML documents and to transform XML into other formats such as HTML.

What is XSL?

  1. Definition

    XSL (Extensible Stylesheet Language) is a family of technologies used for working with XML documents.

  2. XSLT

    Used to transform XML into HTML, XML or plain text.

  3. XPath

    Used to select elements, attributes and values from XML.

  4. XSL-FO

    Used for formatting documents, especially paginated output.

What is XSLT?

  1. Definition

    XSLT (Extensible Stylesheet Language Transformations) is used to transform XML documents into another format.

    It reads the XML document, selects required elements using XPath and applies templates to generate output.

  2. Uses of XSLT

    • Convert XML into HTML.
    • Convert XML into another XML format.
    • Convert XML into plain text.
    • Display XML data in table format.

How XSLT Works

  1. Read

    Reads the source XML document.

  2. Select

    Selects elements using XPath.

  3. Apply

    Applies XSLT template rules.

  4. Generate

    Generates the final output.

Example of XML and XSLT

  1. Example of XML source

    <catalog>
    <book id="b101">
        <title>Learning XML</title>
        <author>Asha Rao</author>
        <price>450</price>
    </book>
</catalog>

  2. Example of XSLT stylesheet

    <xsl:stylesheet version="1.0"
    xmlns:xsl="http://www.w3.org/1999/XSL/Transform">

    <xsl:output method="html" indent="yes"/>

    <xsl:template match="/">
        <table>
            <tr>
                <th>ID</th>
                <th>Title</th>
                <th>Author</th>
                <th>Price</th>
            </tr>

            <xsl:for-each select="catalog/book">
                <tr>
                    <td><xsl:value-of select="@id"/></td>
                    <td><xsl:value-of select="title"/></td>
                    <td><xsl:value-of select="author"/></td>
                    <td><xsl:value-of select="price"/></td>
                </tr>
            </xsl:for-each>
        </table>
    </xsl:template>

</xsl:stylesheet>

Important XSLT Elements

ElementPurpose
xsl:stylesheetDefines an XSLT stylesheet.
xsl:templateDefines a template rule.
xsl:for-eachRepeats instructions for selected elements.
xsl:value-ofExtracts the value of an element or attribute.
xsl:outputSpecifies the output format.

XPath

XPath (XML Path Language) is used to navigate and select elements and attributes in an XML document.

XPath ExpressionMeaning
/catalogSelects the catalog root element.
catalog/bookSelects book elements inside catalog.
//bookSelects all book elements.
titleSelects title elements.
@idSelects the ID attribute.
priceSelects price elements.

Connecting XML File to XSLT Stylesheet

  1. How

    An XML file can be connected to an XSLT stylesheet using the xml-stylesheet processing instruction.

  2. Example

    <?xml version="1.0" encoding="UTF-8"?>

<?xml-stylesheet type="text/xsl" href="catalog.xsl"?>

<catalog>
    <book id="b101">
        <title>Learning XML</title>
        <author>Asha Rao</author>
        <price>450</price>
    </book>
</catalog>

  3. Explanation

    • catalog.xml is the XML file.
    • catalog.xsl is the XSLT stylesheet.
    • The browser uses the stylesheet to transform XML into HTML.

JavaScript Example: XML to HTML

  1. HTML code

    <button onclick="transformXML()">Transform XML</button>

<div id="result"></div>

  2. JavaScript code

    function transformXML() {

    let xml = `
    <catalog>
        <book id="b101">
            <title>Learning XML</title>
            <author>Asha Rao</author>
            <price>450</price>
        </book>
    </catalog>`;

    let parser = new DOMParser();
    let data = parser.parseFromString(xml, "text/xml");

    let book = data.getElementsByTagName("book")[0];

    let values = [
        book.getAttribute("id"),
        book.getElementsByTagName("title")[0].textContent,
        book.getElementsByTagName("author")[0].textContent,
        book.getElementsByTagName("price")[0].textContent
    ];

    let table = document.createElement("table");
    table.className = "result-table";

    let head = table.insertRow();
    ["ID", "Title", "Author", "Price"].forEach(function (text) {
        let th = document.createElement("th");
        th.textContent = text;
        head.appendChild(th);
    });

    let row = table.insertRow();
    values.forEach(function (text) {
        row.insertCell().textContent = text;
    });

    let result = document.getElementById("result");
    result.textContent = "";
    result.appendChild(table);
}
