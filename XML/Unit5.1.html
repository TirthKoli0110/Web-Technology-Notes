Introduction to XML

Web Technology  /  Unit 5  /  Topic 1

XML (Extensible Markup Language) is a text-based markup language used to store and transport structured data.

Unlike HTML, XML allows users to create their own tags to describe data.

XML Example

  1. XML code

    <course code="WT205">
    <title>Web Technologies</title>
    <credits>4</credits>
    <instructor>Dr. Mehta</instructor>
</course>

  2. Explanation

    • <course> - Main element.
    • <title> - Stores course name.
    • <credits> - Stores course credits.
    • <instructor> - Stores instructor name.

Features of XML

  1. Extensible

    Users can create their own tags.

  2. Structured

    Data is arranged in a tree-like structure.

  3. Portable

    XML can be read by humans and software.

  4. Text-based

    XML stores data in readable text format.

  5. Platform independent

    XML works across different systems.

Difference between XML and HTML

XMLHTML
Used to store and transport data.Used to display data on web pages.
Allows custom tags.Uses predefined tags.
Focuses on data meaning.Focuses on data presentation.
Tags are case-sensitive.Tags are generally case-insensitive.
Does not automatically create a user interface.Displays content in a browser.

JavaScript Example

  1. HTML code

    <p id="result">Click the button to display XML data.</p>

<button onclick="showXML()">Show XML Data</button>

  2. JavaScript code

    function showXML() {
    let xml = "<course><title>Web Technologies</title><credits>4</credits></course>";

    let parser = new DOMParser();
    let data = parser.parseFromString(xml, "text/xml");

    let title = data.getElementsByTagName("title")[0].textContent;
    let credits = data.getElementsByTagName("credits")[0].textContent;

    document.getElementById("result").textContent =
        "Course: " + title + "\nCredits: " + credits;
}

  3. Try it

    Click the button to read the XML text with DOMParser and display two of its values.

    Click the button to display XML data.
