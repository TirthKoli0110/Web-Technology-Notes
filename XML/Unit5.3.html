XML Key Components

Web Technology  /  Unit 5  /  Topic 3

An XML document consists of different components arranged in a tree structure.

Example of XML

  1. XML code

    <?xml version="1.0" encoding="UTF-8"?>
<student id="s-204" status="active">
    <name>Mira Shah</name>
    <programme>B.Tech CSE</programme>
    <marks subject="XML">88</marks>
    <!-- A student record -->
</student>

Main Components

ComponentMeaning
XML DeclarationSpecifies XML version and character encoding.
ElementA named unit of data enclosed in tags.
Root ElementThe single outermost element of an XML document.
AttributeProvides additional information about an element.
Text NodeActual text or data stored inside an element.
CommentA note for readers that is not part of document data.

XML Syntax Rules to Remember

  1. Case-sensitive

    XML element names are case-sensitive.

  2. Close every element

    Every opened element must be closed.

  3. Proper nesting

    Elements must be properly nested.

  4. One root

    There must be exactly one root element.

  5. Quoted attributes

    Attribute values must be written inside quotes.

  6. Empty elements

    Empty elements can be written as <image/>.

Reserved Characters in XML

  1. Entities

    CharacterXML Entity
    &&amp;
    <&lt;
    >&gt;
    "&quot;
    '&apos;

  2. Example

    <message>Tom &amp; Jerry</message>

    Output: Tom & Jerry

XML Namespaces

  1. What it is

    A namespace prevents naming conflicts when XML documents use elements from different sources.

    A namespace is declared using the xmlns attribute and is connected to a URI.

  2. Example

    <course xmlns:lib="https://example.edu/library">
    <title>Web Technologies</title>
    <lib:title>XML for Libraries</lib:title>
</course>

  3. Explanation

    • title belongs to the default namespace.
    • lib:title belongs to the library namespace.
    • Both names are treated as different elements.

JavaScript Example

  1. HTML code

    <button onclick="showStudent()">Show Student Details</button>

<p id="result"></p>

  2. JavaScript code

    function showStudent() {

    let xml = `
    <student id="s-204">
        <name>Mira Shah</name>
        <programme>B.Tech CSE</programme>
        <marks>88</marks>
    </student>`;

    let parser = new DOMParser();
    let data = parser.parseFromString(xml, "text/xml");

    let name = data.getElementsByTagName("name")[0].textContent;
    let programme = data.getElementsByTagName("programme")[0].textContent;
    let marks = data.getElementsByTagName("marks")[0].textContent;

    document.getElementById("result").textContent =
        "Name: " + name + "\n" +
        "Programme: " + programme + "\n" +
        "Marks: " + marks;
}

  3. Try it

    Click the button to read the XML text with DOMParser and display the student information.

    Click the button to display student information.
