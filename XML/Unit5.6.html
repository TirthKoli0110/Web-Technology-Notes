Important Points – Unit 5 at a Glance

Web Technology  /  Unit 5  /  Topic 5

A quick revision of the seven most important points of Unit 5 (XML).

Unit 5 at a Glance

  1. XML

    XML is an extensible, text-based language used to store and transport structured data.

  2. Document tree

    XML elements, attributes, text and namespaces form the document tree.

  3. Well-formedness

    Well-formedness checks XML syntax rules.

  4. DTD and XSD

    DTD and XSD define the structure and rules of XML documents.

  5. XSD vs DTD

    XSD supports advanced data types and constraints compared to DTD.

  6. XPath

    XPath selects elements, attributes and values from XML.

  7. XSLT

    XSLT transforms XML into HTML, XML or plain text.

JavaScript Example

  1. HTML code

    <button onclick="showPoints()">Show Important Points</button>

<div id="result"></div>

  2. JavaScript code

    function showPoints() {

    let points = [
        "XML stores and transports structured data.",
        "Elements, attributes, text and namespaces form the document tree.",
        "Well-formedness checks XML syntax rules.",
        "DTD and XSD define XML document structure.",
        "XSD supports advanced data types and constraints.",
        "XPath selects elements, attributes and values.",
        "XSLT transforms XML into HTML, XML or plain text."
    ];

    let list = document.createElement("ul");

    points.forEach(function (text) {
        let item = document.createElement("li");
        item.textContent = text;
        list.appendChild(item);
    });

    let result = document.getElementById("result");
    result.textContent = "";
    result.appendChild(list);
}

  3. Try it

    Click the button to display all important points as a list. Clicking again rebuilds the list, so the points never repeat.
