DTD and XML Schema (XSD)

Web Technology  /  Unit 5  /  Topic 3

Well-formedness checks XML syntax, but it does not check whether the document follows a particular structure.

For this purpose, XML uses DTD and XSD.

A. DTD (Document Type Definition)

  1. What it is

    DTD defines the basic structure and rules of an XML document.

  2. It specifies

    • Elements.
    • Attributes.
    • Entities.
    • Content models.
    • Order of elements.

  3. Example of DTD

    <!ELEMENT catalog (product+)>
<!ELEMENT product (name, price)>
<!ATTLIST product id ID #REQUIRED>
<!ELEMENT name (#PCDATA)>
<!ELEMENT price (#PCDATA)>

  4. Explanation

    • catalog must contain one or more products.
    • Each product must contain name followed by price.
    • Every product must have an ID attribute.
    • name and price contain text data.

B. XML Schema (XSD)

  1. What it is

    XSD stands for XML Schema Definition. It defines the structure and data types of XML documents.

  2. Features of XSD

    • Supports built-in data types such as string, decimal and date.
    • Supports attributes and elements.
    • Supports namespaces.
    • Allows restrictions and constraints.
    • Provides stronger validation than DTD.

  3. Example of XSD

    <xs:schema xmlns:xs="http://www.w3.org/2001/XMLSchema">

    <xs:element name="catalog">
        <xs:complexType>
            <xs:sequence>
                <xs:element name="product"
                    maxOccurs="unbounded">
                    <xs:complexType>
                        <xs:sequence>
                            <xs:element name="name"
                                type="xs:string"/>
                            <xs:element name="price"
                                type="xs:decimal"/>
                        </xs:sequence>

                        <xs:attribute name="id"
                            type="xs:ID" use="required"/>
                    </xs:complexType>
                </xs:element>
            </xs:sequence>
        </xs:complexType>
    </xs:element>

</xs:schema>

Difference between DTD and XSD

DTDXSD
Uses specialized DTD syntax.Uses XML syntax.
Supports limited data types.Supports many built-in data types.
Limited namespace support.Supports namespaces.
Provides basic validation.Provides advanced validation.
Suitable for simple structures.Suitable for complex structures.

XSD is more powerful than DTD because it supports data types, namespaces and detailed restrictions.

XML Validation

  1. What it is

    XML validation checks whether an XML document follows the rules defined in DTD or XSD.

  2. DTD validation command

    xmllint --noout --valid catalog.xml

  3. XSD validation command

    xmllint --noout --schema catalog.xsd catalog.xml

    If the document follows all the defined rules, validation is successful.

JavaScript Example

  1. HTML code

    <label for="price">Product Price:</label>

<input type="text" id="price" placeholder="Enter price">

<button onclick="checkPrice()">Check Price</button>

<p id="result"></p>

  2. JavaScript code

    function checkPrice() {

    let price = document.getElementById("price").value.trim();

    if (price === "" || isNaN(price) || Number(price) < 0) {
        document.getElementById("result").textContent =
            "Invalid Price. Enter a valid decimal number.";
    } else {
        document.getElementById("result").textContent =
            "Valid Price: " + Number(price);
    }
}

  3. Try it

    Enter a product price and click the button to check it. This is the same idea as the xs:decimal type in the XSD above: the value must be a number.
