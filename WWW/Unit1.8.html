Web Server

A web server is a computer/software system that stores and delivers web content to clients.

Functions

  1. Receives requests

    Receives HTTP requests.

  2. Processes requests

    Processes the requests it receives.

  3. Finds the resource

    Finds the required webpage/resource.

  4. Sends responses

    Sends HTTP responses to browsers.

  5. Stores resources

    Stores website resources.

  6. Hosts websites

    Hosts websites so that users can access them.
