HTTP

HTTP = HyperText Transfer Protocol. It is a communication protocol used between web browsers and web servers.

When you visit a website

  1. Browser sends an HTTP Request

    The browser asks the server for a page or data.

  2. Server sends an HTTP Response

    The server replies with the requested content.

HTTP Request

  1. HTTP Version

    Specifies the HTTP version being used.

    Example: HTTP/1.1

  2. HTTP Method

    Specifies what action is required.

    GET – retrieve data
    POST – send data to the server

  3. Request Headers

    Provide additional information about the request, such as browser type and content type.

  4. Request Body

    Contains data sent to the server, commonly when submitting a form.
