String Processing and Regular Expressions

Web Technology  /  Unit 6  /  Topic 5

A. What is a String?

A string is a sequence of characters or text.

  1. Example:

    $name = "Hello PHP";

PHP provides built-in functions to manipulate strings.

B. Important PHP String Functions

FunctionPurposeExample
trim()Removes whitespace from both ends.trim(" PHP ")
strlen()Counts bytes in a string.strlen("Hello")
mb_strlen()Counts characters in multibyte text.mb_strlen("Hello")
str_replace()Replaces literal text.str_replace("PHP", "Web", $text)
strtolower()Converts text to lowercase.strtolower("HELLO")
strtoupper()Converts text to uppercase.strtoupper("hello")
substr()Extracts part of a string.substr("Hello", 0, 2)

  1. PHP Example:

    <?php
$text = "  Hello PHP  ";

echo trim($text);
echo "<br>";

echo strlen(trim($text));
echo "<br>";

echo str_replace("PHP", "World", trim($text));
?>

  2. Output:

    Hello PHP
    9
    Hello World

C. What are Regular Expressions (Regex)?

A regular expression is a pattern used to search, match, validate or replace text.

Examples:

  • Checking an email-like format.
  • Finding numbers in text.
  • Checking whether a string contains only digits.
  • Replacing matching patterns.

PHP uses PCRE regular expression functions.

Important Regex Functions:

FunctionPurpose
preg_match()Checks whether a pattern matches.
preg_replace()Replaces text matching a pattern.
preg_split()Splits text using a pattern.

D. Regex Symbols

SymbolMeaning
/ /Pattern delimiters.
^Start of string.
$End of string.
[A-Z]Any uppercase letter.
[a-z]Any lowercase letter.
[0-9]Any digit.
+One or more occurrences.
*Zero or more occurrences.
.Any character except newline by default.
\dAny digit.
\DAny non-digit.
iCase-insensitive matching.

E. Regex Example - Email-like Validation

  1. PHP code

    <?php
$email = "learner@example.edu";

$pattern = '/^[A-Z0-9._%+-]+@[A-Z0-9.-]+\.[A-Z]{2,}$/i';

if (preg_match($pattern, $email)) {
    echo "Email-like format found";
} else {
    echo "Invalid format";
}
?>

Explanation:

PartMeaning
^Starts matching from the beginning.
[A-Z0-9._%+-]+Matches the first part.
@Matches the @ symbol.
[A-Z0-9.-]+Matches the domain name.
\.Matches a literal dot.
[A-Z]{2,}Matches at least two letters.
$Ends matching at the end.
iIgnores uppercase and lowercase differences.

This checks an email-like format, not whether the email address actually exists.

F. Regex Example - Extracting Digits

  1. PHP code

    <?php
$phone = "(555) 123-4567";

$digits = preg_replace('/\D+/', '', $phone);

echo $digits;
?>

  2. Output:

    5551234567

Here, \D matches non-digit characters, and preg_replace() removes them.

JavaScript Example - String Processing

  1. HTML code

    <form id="textForm" onsubmit="return processText()">
    <label for="mytext">Enter Text:</label>
    <input type="text" id="mytext" required>

    <button type="submit">Process Text</button>
    <button type="reset">Reset</button>
</form>

  2. JavaScript code

    function processText() {
    let text = document.getElementById("mytext").value;

    let lines = [
        "Uppercase: " + text.toUpperCase(),
        "Lowercase: " + text.toLowerCase(),
        "Length: " + text.length,
        "Trimmed: " + text.trim()
    ];

    document.getElementById("textForm").reset();   // clear the field

    let result = document.getElementById("result");

    lines.forEach(function (line) {
        let row = document.createElement("div");
        row.textContent = line;
        result.appendChild(row);
    });

    return false;
}

// The Reset button clears the field and the output
document.getElementById("textForm").addEventListener("reset", function () {
    document.getElementById("result").textContent = "";
});

    The lines are added with textContent, so any HTML you type is shown as plain text (output escaping).

  3. Try it

    Enter some text to perform string operations. After processing, the field clears itself. Click Reset to clear the field and the output.
