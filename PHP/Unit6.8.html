Important Security Concepts

Web Technology  /  Unit 6  /  Topic 8

These concepts are important for both practical programming and theory examinations.

Important Security Concepts

Security ConceptExplanation
Input ValidationChecks whether user input meets application rules.
Output EscapingPrevents user input from being interpreted as HTML.
Prepared StatementsHelp prevent SQL injection.
Password ProtectionPasswords should be securely hashed, not stored as plain text.
HTTPSProtects data while travelling between browser and server.
Server-Side ExecutionKeeps PHP source code on the server.

Example of Safe Output

  1. PHP code

    <?php
$name = "<script>alert('Hello')</script>";

echo htmlspecialchars($name, ENT_QUOTES, 'UTF-8');
?>

  2. Explanation

    • $name: Stores the user input.
    • htmlspecialchars(): Converts special HTML characters into safe text.
    • ENT_QUOTES: Converts both single and double quotes.
    • UTF-8: Specifies the character encoding.

  3. What the browser receives

    &lt;script&gt;alert(&#039;Hello&#039;)&lt;/script&gt;

  4. Output

    Instead of executing the script, the browser displays it as text.

    <script>alert('Hello')</script>

JavaScript Example - Input Validation

  1. HTML code

    <form onsubmit="return checkName()">

    <label for="username">Enter Name:</label>

    <input type="text" id="username">

    <button type="submit">Check</button>

</form>

<p id="result"></p>

  2. JavaScript code

    function checkName() {

    let name = document.getElementById("username").value.trim();

    if (name === "") {
        document.getElementById("result").textContent =
            "Please enter your name.";
    } else {
        document.getElementById("result").textContent =
            "Input is valid. Welcome " + name;
    }

    return false;
}

  3. Try it

    Enter your name to check the input. Try leaving it empty, or typing only spaces.

Remember for Exams

  1. Input validation

    Input validation checks user input.

  2. Output escaping

    Output escaping protects displayed content.

  3. Prepared statements

    Prepared statements help prevent SQL injection.

  4. Password hashing

    Password hashing protects stored passwords.

  5. HTTPS

    HTTPS protects data during transmission.

  6. PHP on the server

    PHP runs on the server.
