Types, Variables, Arrays and Output

A. Arrays in PHP

An array is a variable that stores multiple values in a single variable.

  1. 1. Indexed Array

    Stores values using numeric indexes starting from 0.

    <?php
$subjects = ["PHP", "HTML", "CSS"];

echo $subjects[0];
echo $subjects[1];
?>

  2. 2. Associative Array

    Stores values using named keys.

    <?php
$marks = [
    "Mira" => 88,
    "Dev" => 76
];

echo $marks["Mira"];
?>

  3. 3. Multidimensional Array

    An array containing one or more arrays.

    <?php
$students = [
    ["Mira", 88],
    ["Dev", 76]
];

echo $students[0][0];
?>

B. Output Statements

PHP provides two commonly used output statements:

StatementPurpose

printDisplays a string and returns the value 1.

  1. Example:

    <?php
$name = "Asha";

echo "Hello ";
print $name;
?>

C. Loops in PHP

Loops are used to execute a block of code repeatedly.

  1. 1. For Loop

    Used when the number of repetitions is known.

    <?php
for ($i = 1; $i <= 5; $i++) {
    echo $i . "<br>";
}
?>

    Output: 1, 2, 3, 4, 5

  2. 2. While Loop

    Executes while a condition is true.

    <?php
$i = 1;

while ($i <= 5) {
    echo $i;
    $i++;
}
?>

  3. 3. Foreach Loop

    Used especially for arrays.

    <?php
$subjects = ["PHP", "HTML", "CSS"];

foreach ($subjects as $subject) {
    echo $subject . "<br>";
}
?>

Difference Between Loops

LoopUse
ForWhen repetitions are known.
WhileWhen repetition depends on a condition.
ForeachWhen processing array elements.

D. Conditions in PHP

Conditions help a program make decisions.

  1. If-Else Statement

    <?php
$marks = 85;

if ($marks >= 40) {
    echo "Pass";
} else {
    echo "Fail";
}
?>

Explanation:

  • If marks are 40 or more, display Pass.
  • Otherwise, display Fail.

E. Functions in PHP

A function is a reusable block of code that performs a particular task.

  1. Example:

    <?php
function greet($name) {
    return "Hello " . $name;
}

echo greet("Asha");
?>

    Output: Hello Asha

  2. Function with Return Type

    <?php
function resultLabel(int $marks): string {
    if ($marks >= 40) {
        return "Pass";
    }

    return "Needs more practice";
}

echo resultLabel(88);
?>

Advantages of Functions:

  • Code reusability.
  • Reduces repetition.
  • Makes programs easier to understand.
  • Makes debugging easier.

Explanation of the return type example:

PartMeaning
intSpecifies the parameter type.
stringSpecifies the return type.
returnSends a value back to the calling code.
