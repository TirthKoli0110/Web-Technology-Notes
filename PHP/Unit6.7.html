Running PHP Programs

Web Technology  /  Unit 6  /  Topic 7

PHP programs can be executed in two main ways: with the PHP development server and with the command line (CLI).

A. Using the PHP Development Server

  1. Create the file

    First, create a PHP file named hello.php.

    <?php
echo "Hello PHP!";
?>

  2. Start the server

    Open the terminal in the folder containing the file and run:

    php -S localhost:8000

  3. Open the address

    Then open this address in your browser:

    http://localhost:8000/hello.php

  4. Output

    Hello PHP!

B. Using the Command Line (CLI)

  1. What it is

    CLI stands for Command Line Interface. It is used to run PHP programs directly from the terminal.

  2. Command

    php hello.php

  3. Output

    Hello PHP!

Difference Between PHP CLI and Development Server

PHP CLIPHP Development Server
Runs PHP through the terminal.Runs PHP through a local web server.
Output appears in terminal.Output appears in browser.
Useful for scripts and practice.Useful for testing websites and forms.

C. Laravel Framework Example

  1. What it is

    Laravel is a popular PHP framework.

  2. Create a Laravel project

    composer create-project laravel/laravel php-framework-demo

  3. Move into the project folder

    cd php-framework-demo

  4. Start the Laravel development server

    php artisan serve

  5. Open the address

    Usually, open this address:

    http://127.0.0.1:8000

Laravel Route Example

  1. Add a route

    In routes/web.php:

    <?php

use Illuminate\Support\Facades\Route;

Route::get('/hello/{name}', function (string $name) {
    return view('hello', ['name' => $name]);
});

  2. Create a template

    File: resources/views/hello.blade.php

    <!doctype html>
<html lang="en">
<head>
    <title>Framework Greeting</title>
</head>
<body>
    <h1>Hello, {{ $name }}!</h1>
    <p>This page is returned through a Laravel route and view.</p>
</body>
</html>

  3. Visit the address

    If you visit:

    http://127.0.0.1:8000/hello/Asha

  4. Browser output

    Hello, Asha!
    This page is returned through a Laravel route and view.

Important Terms

  • Composer: PHP dependency manager.
  • Laravel: PHP framework.
  • Artisan: Laravel command-line tool.
  • Route: Defines which code handles a URL.
  • Blade: Laravel's templating engine.
  • View: Page or template displayed to the user.

JavaScript Example

  1. HTML code

    <button onclick="showCommand()">Show Command</button>

<p id="result"></p>

  2. JavaScript code

    function showCommand() {
    document.getElementById("result").textContent =
        "PHP CLI Command: php hello.php";
}

  3. Try it

    Click the button to display a PHP command. This only shows the command as text. It does not run any PHP, because PHP runs on a server or in a terminal, not in the browser.

Important Note

The Laravel example requires Composer, a supported PHP version and project dependencies. It cannot run simply by opening this HTML file.
