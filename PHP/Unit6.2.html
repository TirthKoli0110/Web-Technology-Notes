Introduction and Basic Syntax of PHP

Web Technology  /  Unit 6  /  Topic 2

What is PHP?

PHP stands for PHP: Hypertext Preprocessor. It is an open-source, server-side scripting language used to develop dynamic websites and web applications.

Features of PHP:

  • Open-source and free.
  • Runs on the server.
  • Can be embedded inside HTML.
  • Supports databases.
  • Used for dynamic webpages.
  • Supports functions, arrays, loops and conditions.

Basic PHP Syntax

PHP code is written inside PHP tags:

<?php
    echo "Hello World!";
?>

Explanation:

PartMeaning
<?phpStarts PHP code.
echoDisplays output.
"Hello World!"Text to display.
;Ends a PHP statement.
?>Closes the PHP block.

Important Rules:

  1. Rule 1

    PHP variables start with $.

  2. Rule 2

    Statements generally end with a semicolon (;).

  3. Rule 3

    Variable names are case-sensitive.

  4. Rule 4

    Keywords and function names are generally case-insensitive.

  5. Rule 5

    Comments use // or /* ... */.

PHP Variables and Data Types

A variable is a named memory location used to store data.

  1. Example

    <?php
$name = "Asha";
$age = 20;
$passed = true;
$marks = 88.5;

echo $name;
?>

Operators in PHP

Operators are symbols used to perform operations on values.

Operator TypeExamplesPurpose
Arithmetic+ - * / %Mathematical calculations
Comparison== != > < >= <=Compare values
Assignment= += -=Assign values
Logical&& || !Combine conditions
Concatenation.Join strings

PHP Operators Example

  1. PHP code

    <?php
$a = 10;
$b = 5;

echo $a + $b;  // 15
echo $a * $b;  // 50
echo "Hello " . "PHP";
?>

  2. JavaScript Example

    function calculate() {
    let a = 10;
    let b = 5;

    let add = a + b;
    let multiply = a * b;

    document.getElementById("result").innerHTML =
        "Addition = " + add +
        "<br>Multiplication = " + multiply;
}

  3. Try it

    PHP runs only on a server, so this button runs the same calculations in JavaScript. Click it to perform addition and multiplication.

Remember:

PHP uses the dot (.) operator to join strings, unlike Java or JavaScript, which commonly use +.
