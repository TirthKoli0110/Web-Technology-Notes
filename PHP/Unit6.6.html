What is a Framework?

A framework is a reusable structure that provides tools, libraries and rules for developing applications.

In PHP, frameworks help developers build websites faster and in an organized way.

Advantages:

  • Saves development time.
  • Provides reusable code.
  • Improves code organization.
  • Supports routing and database operations.
  • Provides security-related features.
  • Makes large applications easier to maintain.

MVC Architecture

MVC stands for Model - View - Controller. It is a software design pattern that separates an application into three main parts.

Three Main Components of MVC

ComponentWork
ModelManages data and database operations.
ControllerReceives requests and coordinates the application.
ViewDisplays the output to the user.

Conceptual Roles of MVC Components

  1. 1. Model

    • Represents application data.
    • Handles database operations.
    • Contains business rules.

    Example: Fetching student marks from a database.

  2. 2. View

    • Represents the user interface.
    • Displays information.
    • Usually uses HTML templates.

    Example: Displaying student marks on a webpage.

  3. 3. Controller

    • Receives user requests.
    • Processes the request.
    • Communicates with the Model.
    • Selects the appropriate View or response.

    Example: Receiving a request to display student results.

Easy Way to Remember:

  • Model = Data
  • View = Design / Display
  • Controller = Control / Coordination

Common PHP Frameworks

FrameworkDescriptionCommon Use
LaravelFull-featured framework with routing, Blade templates, ORM and migrations.Modern web applications.
SymfonyModular framework with reusable components.Large and complex applications.
CodeIgniterLightweight framework with straightforward setup.Smaller projects.

Comparison of PHP Frameworks

  1. 1. Laravel

    • Provides many built-in features.
    • Supports database management.
    • Uses Blade templating.
    • Suitable for modern applications.

  2. 2. Symfony

    • Provides reusable components.
    • Highly configurable.
    • Suitable for complex projects.

  3. 3. CodeIgniter

    • Lightweight.
    • Relatively simple to learn.
    • Has a smaller footprint.
