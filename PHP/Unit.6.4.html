Handling a Form Safely

Web Technology  /  Unit 6  /  Topic 4

What is a PHP Form?

A form is used to collect information from users. PHP can receive and process the submitted information.

Examples:

  • Name
  • Email
  • Password
  • Phone number

GET vs POST

GETPOST
Sends data through URL parameters.Sends data in the request body.
Data can appear in browser history and URLs.Data is not normally displayed in the URL.
Suitable for searches and retrieving information.Suitable for submitting form data.
Not suitable for sensitive information.HTTPS is still required for sensitive data.

Example of an HTML Form

<form method="post">
    <label>Your name:</label>

    <input
        type="text"
        name="name"
        required
    >

    <button type="submit">Submit</button>
</form>

Processing the Form Using PHP

<?php
if ($_SERVER['REQUEST_METHOD'] === 'POST') {

    $name = trim($_POST['name'] ?? '');

    if ($name === '') {
        echo "Please enter your name.";
    } else {
        echo "Welcome, " .
            htmlspecialchars($name, ENT_QUOTES, 'UTF-8');
    }
}
?>

Explanation of Important Terms

TermMeaning
$_POSTCollects submitted POST data.
$_GETCollects data from URL parameters.
$_SERVERContains server and request information.
trim()Removes whitespace from beginning and end.
htmlspecialchars()Converts special HTML characters into safe representations.
REQUEST_METHODIdentifies the HTTP request method.

Important Security Concepts

  1. 1. Input Validation

    Checks whether submitted data meets the required rules. Example: Checking whether a name is empty or has an acceptable length.

  2. 2. Output Escaping

    Converts special characters so user input is displayed as text instead of being interpreted as HTML.

  3. 3. SQL Injection Prevention

    Never insert user input directly into SQL queries. Use prepared statements.

JavaScript Form Example

  1. HTML code

    <form id="nameForm" onsubmit="return showName()">
    <label for="username">Your Name:</label>
    <input type="text" id="username" required>

    <button type="submit">Submit</button>
    <button type="reset">Reset</button>
</form>

  2. JavaScript code

    function showName() {
    let name = document.getElementById("username").value.trim();

    if (name === "") {
        document.getElementById("result").textContent =
            "Please enter your name.";
    } else {
        document.getElementById("nameForm").reset();   // clear the field

        document.getElementById("result").textContent =
            "Welcome, " + name;
    }

    return false;
}

// The Reset button clears the field and the message
document.getElementById("nameForm").addEventListener("reset", function () {
    document.getElementById("result").textContent = "";
});

  3. Try it

    Enter your name and click Submit. After a successful submit the field clears itself. Click Reset to clear the field and the message.

Remember for Exams:

Validation checks whether input is acceptable; escaping protects the output context.
