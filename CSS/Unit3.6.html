Inheritance and the Cascade

Web Technology  /  CSS  /  Lesson 6

Learn how CSS properties are passed from parent elements to child elements and how the browser chooses CSS values.

1. What is Inheritance?

  1. Meaning

    Inheritance means some CSS properties automatically receive their values from a parent element.

  2. Example

    .article {
    color: darkblue;
    border: 1px solid gray;
}

.article p {
    font-family: Georgia, serif;
}

  3. HTML Example

    <div class="article">
    <p>This is an article paragraph.</p>
</div>

  4. Explanation

    • The paragraph inherits the text color from its parent.
    • The paragraph uses the specified Georgia font family.
    • The parent's border does not automatically pass to the paragraph.

2. Common Inherited Properties

  • color: Text color.
  • font-family: Font style.
  • font-size: Text size.
  • line-height: Space between lines.

3. Common Non-Inherited Properties

  • margin: Space outside an element.
  • padding: Space inside an element.
  • border: Element boundary.
  • width: Element width.
  • height: Element height.

5. Important: Cascade and Inheritance

The cascade determines the applicable value for an element first. If an inherited property has no applicable value on the child, the child can receive that value from its parent.

Remember:
Inheritance and the cascade work together.

6. CSS Debugging Tips

If a CSS rule does not work, check these things:

  1. Spelling of properties and values.

  2. Missing semicolons.

  3. Missing or mismatched braces.

  4. Whether the selector matches the HTML element.

  5. Whether another rule overrides the declaration.

7. Quick Quiz

  1. Question 1: Which property is commonly inherited?

  2. Question 2: Does border automatically inherit from a parent?

  3. Question 3: What determines the applicable CSS value?

8. Summary

  • Inheritance passes certain CSS values from parent to child.
  • Color, font-family, font-size and line-height are commonly inherited.
  • Margin, padding, border, width and height are not inherited by default.
  • The cascade determines applicable values before inheritance is used.
  • Always check selectors and overriding rules when debugging CSS.
