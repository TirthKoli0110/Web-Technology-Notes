Revise these important CSS concepts before your examination. This lesson covers all 22 important revision points, followed by a reference table, flashcards and a practice quiz.

1. CSS Fundamentals

  1. CSS

    CSS (Cascading Style Sheets) controls the presentation and layout of HTML content.

  2. Three methods of adding CSS

    MethodWhere it is written
    Inline CSSInside an HTML element using the style attribute.
    Internal CSSInside a style element in the HTML document's head.
    External CSSIn a separate .css file.

  3. CSS syntax

    selector {
    property: value;
}

  4. Class selector

    Begins with a dot (.) and selects elements with a particular class.

    .notice { color: blue; }

  5. ID selector

    Begins with # and selects an element with a particular ID.

    #main-title { color: red; }

  6. Universal selector

    The * selector selects all elements.

    * { box-sizing: border-box; }

2. Cascade and Inheritance

  1. Cascade

    The cascade resolves competing CSS declarations using origin, importance, specificity and source order, among other rules.

  2. Inheritance

    Inheritance allows certain property values to pass from parent elements to child elements.

3. CSS Units and Custom Properties

  1. CSS units

    UnitMeaning
    pxPixels
    remRelative to the root font size
    emRelative to the element's font size
    %Percentage of a reference value
    vwViewport width
    vhViewport height

  2. Custom properties

    Custom properties store reusable CSS values.

    :root {
    --brand-color: cyan;
}

h1 {
    color: var(--brand-color);
}

4. Colors and Typography

  1. CSS colors

    FormatExample
    Color namesred, blue, green
    Hexadecimal#00FFFF
    RGBrgb(0, 255, 255)
    RGBArgba(0, 255, 255, 0.5)
    HSLhsl(180, 100%, 50%)

  2. Typography

    Typography controls the appearance of text.

    PropertyPurpose
    font-familyDefines the font.
    font-sizeDefines the text size.
    font-weightDefines the thickness of text.
    line-heightControls the spacing between lines.

5. Borders and Box Model

  1. Borders

    PropertyPurpose
    border-widthThickness
    border-stylePattern
    border-colorColor
    border-radiusRounded corners

  2. CSS Box Model

    The CSS Box Model consists of four parts, from inside to outside:

    PartMeaning
    ContentThe text or images inside the element
    PaddingSpace inside the border
    BorderLine around the padding and content
    MarginSpace outside the border

  3. Content-box

    The declared width applies to the content only.

  4. Border-box

    The declared width includes content, padding and border.

    Try changing the box sizing. Both use a width of 250px, padding of 20px and a border of 5px.

6. Positioning and Layout

  1. CSS positioning

    PositionMeaning
    staticDefault positioning.
    relativePositioned relative to its normal position.
    absolutePositioned relative to its nearest positioned ancestor.
    fixedPositioned relative to the viewport.
    stickyActs relatively until its scrolling threshold is reached.

  2. Flexbox

    Flexbox is a one-dimensional layout system. It arranges items mainly in a row or column.

  3. CSS Grid

    Grid is a two-dimensional layout system. It arranges items in rows and columns.

7. Responsive and Modern CSS

  1. Media queries

    Media queries apply styles when specified conditions are met.

    @media (max-width: 600px) {
    .container {
        grid-template-columns: 1fr;
    }
}

  2. Responsive design

    Responsive design helps webpages adapt to different screen sizes, including mobile phones, tablets and computers.

  3. Modern CSS features

    FeaturePurpose
    GradientsSmooth color transitions
    Box shadowsShadows around elements
    TransformsScale, rotate, move or skew
    TransitionsGradual changes
    FlexboxOne-dimensional layouts
    GridTwo-dimensional layouts
