Text, Fonts and Typography

Web Technology  /  CSS  /  Lesson 8

Typography refers to the appearance and arrangement of text on a webpage. CSS controls fonts, size, weight, alignment, spacing and decoration.

1. Important Typography Properties

  1. Properties

    PropertyExamplePurpose
    font-familyGeorgia, serifSets the typeface.
    font-size1.1remSets text size.
    font-weight700 or boldControls text thickness.
    text-aligncenterAligns text horizontally.
    line-height1.6Controls line spacing.
    text-decorationunderlineAdds or removes decoration.
    text-transformuppercaseChanges displayed letter case.

2. Typography Example

  1. CSS code

    p {
    font-family: Georgia, serif;
    font-size: 1rem;
    font-weight: 400;
    text-align: justify;
    line-height: 1.6;
}

  2. Explanation

    PropertyWhat it does
    font-familySpecifies the preferred font and fallback family.
    font-sizeControls the size of text.
    font-weightControls character thickness.
    text-alignDetermines horizontal alignment.
    line-heightControls vertical space between lines.
    text-decorationControls underlines and related effects.
    text-transformChanges displayed capitalization.
