These tags mark quotations, abbreviations, contact details, titles of works and text direction.

Quotation & Citation Tags

TagPurposeExample Output
<abbr>AbbreviationWHO
<address>Contact Information
John Doe
India
<blockquote>Long Quotation
Learning never ends.
<q>Short QuotationHe said Hello
<cite>Creative Work TitleWings of Fire
<bdo>Change Text DirectionHello

1. <abbr>

  1. Syntax

    <abbr title="World Health Organization">WHO</abbr>

  2. Output

    WHO

2. <address>

  1. Syntax

    <address>
John Doe
India
</address>

  2. Output

    John Doe
    India

3. <blockquote>

  1. Syntax

    <blockquote>
Learning never ends.
</blockquote>

  2. Output

    Learning never ends.

  3. Purpose

    Displays a long quotation.

4. <q>

  1. Syntax

    <p>
He said <q>Hello</q>
</p>

  2. Output

    He said Hello.

  3. Purpose

    Displays a short quotation.

5. <cite>

  1. Syntax

    <cite>Wings of Fire</cite>

  2. Output

    Wings of Fire

  3. Purpose

    Displays the title of a creative work.

6. <bdo>

  1. Syntax

    <bdo dir="rtl">Hello</bdo>

  2. Output

    Normal: Hello

    RTL: Hello

  3. Purpose

    Changes the text direction.
