Responsive Web Design

Web Technology  /  CSS  /  Lesson 14

Responsive Web Design allows a webpage to adapt to different screen sizes and viewing conditions. A responsive webpage should work properly on mobile phones, tablets, laptops and desktop computers.

1. What is Responsive Web Design?

  1. Definition

    Responsive Web Design makes a website adjust its layout and content according to the available screen size.

  2. Example

    DeviceLayout
    MobileContent appears in a single column.
    TabletContent may appear in two columns.
    DesktopContent can appear in three or more columns.

2. Media Queries

  1. Definition

    A media query applies CSS rules only when a specified condition is true.

  2. Example

    .feature-list {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 15px;
}

@media (max-width: 600px) {
    .feature-list {
        grid-template-columns: 1fr;
    }
}

  3. Explanation

    • On wider screens, the grid displays three columns.
    • At 600px or less, the grid changes to one column.
    • This improves readability on smaller screens.

  4. Basic syntax

    @media (condition) {
    selector {
        property: value;
    }
}

  5. Common media query conditions

    ConditionMeaning
    max-widthApplies when the viewport is no wider than a specified width.
    min-widthApplies when the viewport is at least a specified width.
    prefers-reduced-motionDetects whether the user prefers reduced motion.

3. Flexible Layouts

  1. Definition

    CSS provides flexible sizing functions such as minmax() and auto-fit.

  2. Example

    .feature-list {
    display: grid;
    grid-template-columns:
        repeat(auto-fit, minmax(180px, 1fr));
    gap: 15px;
}

  3. Explanation

    CodeWhat it does
    minmax(180px, 1fr)Sets a minimum track size of 180px and allows it to expand.
    auto-fitFits as many grid tracks as practical into the available space.
    1frAllows tracks to share available space.

4. Reduced Motion

  1. Definition

    Some users prefer fewer animations because movement can cause discomfort. CSS can detect this preference using prefers-reduced-motion.

  2. Example

    @media (prefers-reduced-motion: reduce) {
    *,
    *::before,
    *::after {
        transition: none;
        animation: none;
    }
}

  3. Explanation

    • Detects the user's reduced-motion preference.
    • Disables unnecessary transitions.
    • Disables unnecessary animations.
    • Helps make websites more comfortable to use.
