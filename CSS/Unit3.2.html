Three Ways to Add CSS

Web Technology  /  CSS  /  Ways to Add CSS

CSS can be added to an HTML document in three ways: External CSS, Internal CSS and Inline CSS.

2.1 External CSS

  1. What it is

    External CSS is written in a separate .css file and linked to the HTML document.

  2. HTML code

    <link rel="stylesheet" href="style.css">

  3. CSS code (style.css)

    h1 {
  color: blue;
}

  4. Advantages

    The same stylesheet can be used on multiple pages.
    It makes code easier to maintain.
    It keeps HTML and CSS separate.

  5. Use

    Large websites and projects with multiple pages.

2.2 Internal CSS

  1. What it is

    Internal CSS is written inside a <style> element in the HTML document's <head> section.

  2. Example

    <head>
  <style>
    h1 {
      color: green;
    }
  </style>
</head>

  3. Advantages

    Useful for styling a single webpage.
    No separate CSS file is required.

  4. Use

    Standalone pages that need their own styles.

2.3 Inline CSS

  1. What it is

    Inline CSS is written directly inside an HTML element using the style attribute.

  2. Example

    <p style="color: red;">
  This is a paragraph.
</p>

  3. Advantages

    Quickly applies a style to a particular element.

  4. Disadvantages

    Difficult to maintain when used repeatedly.
    Mixes content with presentation.

  5. Use

    Quick demonstrations or one-off styling.
