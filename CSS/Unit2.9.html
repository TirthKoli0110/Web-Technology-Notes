HTML Links

Web Technology  /  HTML  /  Part 2: Links

A hyperlink connects one webpage to another. This page covers the anchor tag and everything you can do with it.

1. Hyperlink

  1. Purpose

    Used to connect one webpage to another.

    <a href="https://example.com">Visit</a>

    Output: Visit

  2. Parts

    <a> → Anchor Tag
    href → Destination URL

2. href Attribute

  1. Purpose

    Specifies the URL (destination) of the hyperlink.

    <a href="https://google.com">Google</a>

    Output: Google

3. target Attribute

  1. Values

    ValueMeaning
    _selfSame tab (Default)
    _blankOpens in a New Tab
    _parentParent Frame
    _topFull Window

  2. Example

    <a href="https://google.com" target="_blank">Google</a>

    Output: Open Google in New Tab

4. Absolute URL vs Relative URL

  1. Comparison

    Absolute URLRelative URL
    Full Web AddressFile Path
    External WebsiteInternal Page
    https://google.comabout.html

5. Image as a Link

  1. Syntax

    Put an image inside the anchor tag to make it clickable.

    <a href="home.html">
  <img src="home.png">
</a>

6. Email Link

  1. Syntax

    <a href="mailto:test@example.com">Send Email</a>

    Output: Send Email

7. Button Link

  1. Syntax

    <button onclick="location.href='home.html'">
  Home
</button>

    Output:

8. title Attribute

  1. Purpose

    The title attribute displays a tooltip when the mouse pointer is placed over a link.

    <a href="page.html" title="Go to Page">Visit</a>

    Output: Hover over this link
