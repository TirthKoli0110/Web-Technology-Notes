Introduction to CSS

Web Technology  /  CSS  /  Introduction

Learn the basics of CSS and web designing.

1. What is CSS?

  1. Definition

    CSS (Cascading Style Sheets) is a stylesheet language used to control the appearance and layout of HTML elements on a webpage.

  2. HTML, CSS and JavaScript

    HTML: Structure of a webpage.
    CSS: Design and presentation.
    JavaScript: Functionality and interaction.

2. Example of CSS

  1. HTML Code

    <p>Welcome to CSS</p>

  2. CSS Code

    p {
  color: blue;
  font-size: 20px;
}

  3. Output

    Welcome to CSS

3. Why is CSS Needed?

  1. Separation of Content and Design

    HTML handles content, while CSS handles styling.

  2. Reusability

    A single stylesheet can be used on multiple webpages.

  3. Responsive Design

    CSS allows webpages to adapt to mobiles, tablets and desktops.

  4. Reduced Repetition

    Reusable CSS rules reduce repeated styling.

  5. Consistency

    A common stylesheet maintains a uniform appearance.
