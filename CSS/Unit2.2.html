HTML Document Rules

  1. Starts with <!DOCTYPE html>

  2. Root element: <html>

  3. Visible content is placed inside <body>

DOCTYPE

<!DOCTYPE html>

Purpose

  1. Declares HTML5 document.

  2. Written at the top of the HTML file.

  3. Written only once.

  4. Helps the browser display the webpage correctly.

Images

Important Attributes

  1. src

    Image location

  2. alt

    Alternative text

  3. width

    Image width

  4. height

    Image height

Example

<img src="image.jpg"
     alt="Girl"
     width="300"
     height="400">

View HTML Source

  1. View Source

  2. Inspect

    Right Click → Inspect

    Inspect shows the HTML and CSS of the webpage.

Nested Elements

HTML elements can be placed inside other HTML elements.

<html>
<body>
    <h1>Heading</h1>
    <p>Paragraph</p>
</body>
</html>
