Most Important Program - Ordered List

  1. Code

    <ol>
  <li>HTML</li>
  <li>CSS</li>
</ol>

  2. Output

    1. HTML
    2. CSS

Most Important Program - Table

  1. Code

    <table border="1" cellpadding="8">
  <tr>
    <th>Name</th>
    <th>Marks</th>
  </tr>
  <tr>
    <td>Rahul</td>
    <td>85</td>
  </tr>
</table>

  2. Output

    NameMarks
    Rahul85

Most Important Program - Image

  1. Code

    <img src="flower.jpg"
     alt="Flower"
     width="300">

Most Important Program - Form

  1. Code

    <form>
  <label>Name</label><br>
  <input type="text">
  <br><br>
  <input type="submit" value="Submit">
</form>

  2. Output

    This sample form does not send data anywhere.
