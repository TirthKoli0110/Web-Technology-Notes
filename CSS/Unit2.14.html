2. HTML Attributes

  1. Syntax

    <tag attribute="value">

  2. Rules

    Use lowercase attribute names.
    Write values inside quotes.
    Write attributes in the opening tag.

  3. Examples

    <img src="flower.jpg" alt="Flower" width="120">
    <a href="home.html">Home Page</a>

3. Inline CSS (Style Attribute)

  1. Syntax

    style="property:value;"

  2. Properties

    PropertyUse
    colorText Color
    background-colorBackground Color
    font-familyFont Style
    font-sizeText Size
    text-alignAlignment
    borderBorder

  3. Example

    <p style="color:red;">Hello World</p>
