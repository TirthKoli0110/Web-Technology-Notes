CSS Values, Units and Custom Properties

Web Technology  /  CSS  /  Values, Units and Custom Properties

A CSS property needs an appropriate value to affect an HTML element.

Types of CSS Values

  1. Value types

    Keywords: bold, center
    Colors: red, #ff6347
    Numbers: 700
    Lengths: 16px, 1rem
    Percentages: 50%
    Functions: linear-gradient()

4.1 CSS Units

CSS units specify sizes, distances and dimensions of HTML elements.

UnitMeaningCommon Use
pxPixel-based CSS lengthBorders and small fixed details
remRelative to root font sizeText sizing and spacing
emRelative to computed font sizeText-related sizing
%Relative to a context determined by the propertyFlexible widths
vw1% of viewport widthViewport-based widths
vh1% of viewport heightViewport-based heights

Unit Examples

  1. Pixels (px)

    Pixels are fixed CSS length units commonly used for borders and small details.

    p {
  font-size: 16px;
}

    Sets the paragraph font size to 16 CSS pixels.

  2. Root em (rem)

    REM is relative to the root element's font size.

    h1 {
  font-size: 2rem;
}

    If the root font size is 16px, then 2rem equals 32px.

  3. Em (em)

    EM is relative to the computed font size of the element, with context-dependent behavior.

    p {
  font-size: 20px;
}

span {
  font-size: 1.5em;
}

    If the parent font size is 20px, then 1.5em equals 30px.

  4. Percentage (%)

    Percentage values are calculated relative to a context determined by the CSS property.

    .container {
  width: 80%;
}

    The container's width is 80% of the relevant containing block's width.

  5. Viewport Units (vw and vh)

    Viewport units are based on the browser's visible area.

    .hero {
  height: 100vh;
}

    Sets the element's height to 100% of the viewport height.

    vw: 1% of viewport width.
    vh: 1% of viewport height.

4.2 Absolute and Relative Sizing

  1. Absolute-style CSS length

    PX is a fixed CSS length unit.

  2. Relative units

    REM, EM, %, VW and VH depend on font size, context or viewport dimensions.

    Relative units are useful for responsive and scalable layouts.

4.3 CSS Custom Properties (Variables)

  1. What they are

    Custom properties store reusable CSS values. They are commonly called CSS variables.

  2. Example

    :root {
  --brand-color: #174678;
  --space-medium: 1rem;
}

.notice {
  color: var(--brand-color);
  padding: var(--space-medium);
}

  3. Explanation

    --brand-color: Stores a color value.
    --space-medium: Stores a spacing value.
    var(): Retrieves a custom property's value.
    :root: Makes variables available throughout the document unless overridden in a more specific scope.

  4. Advantages

    Reduces repeated values.
    Makes the design easier to maintain.
    Allows colors and spacing to be updated consistently.

Important Points to Remember

  1. Remember

    CSS values define how properties behave.
    PX is a fixed CSS length unit.
    REM depends on the root font size.
    EM depends on computed font size.
    Percentage depends on the relevant context.
    VW and VH depend on viewport dimensions.
    CSS variables store reusable values.
    var() retrieves custom property values.
