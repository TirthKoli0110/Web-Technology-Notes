HTML Lists, Tables, Images & Forms

Web Technology  /  HTML  /  Lists, Tables, Images & Forms

This page covers relative URLs, the three kinds of lists, table tags, images and the most common form elements.

1. Relative URL

  1. Definition

    A Relative URL links to files within the same website.

  2. Examples

    <a href="index.html">Home</a>
    <a href="pages/about.html">About</a>
    <a href="../index.html">Home</a>

  3. Relative URL vs Absolute URL

    Relative URLAbsolute URL
    Internal LinkExternal Link
    No Domain NameComplete Web Address
    about.htmlhttps://example.com/about.html
