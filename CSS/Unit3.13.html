Choosing a CSS Layout Method

Web Technology  /  CSS  /  Lesson 13

Modern CSS provides different methods for arranging content on a webpage. The three main layout methods are normal document flow, Flexbox and CSS Grid.

1. Normal Document Flow

  1. Definition

    Normal document flow is the browser's default layout behavior.

    • Block elements generally appear one below another.
    • Inline content flows within a line.
    • Elements are arranged according to document structure.

  2. Use

    Paragraphs, headings and ordinary page content.

  3. Example

    <div>Box 1</div>
<div>Box 2</div>
<div>Box 3</div>

2. Flexbox

  1. Definition

    Flexbox is a one-dimensional layout system. It arranges items in a row or column.

  2. Example

    .container {
    display: flex;
    gap: 10px;
    justify-content: center;
    align-items: center;
}

  3. Explanation

    PropertyWhat it does
    display: flexCreates a flex container.
    gapSets the space between items.
    justify-contentAligns items along the main axis.
    align-itemsAligns items along the cross axis.

  4. Use cases

    • Navigation menus.
    • Buttons in a row.
    • Aligning items inside cards.
    • Arranging content in one direction.

3. CSS Grid

  1. Definition

    CSS Grid is a two-dimensional layout system. It arranges content in rows and columns.

  2. Example

    .feature-list {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 15px;
}

  3. Explanation

    CodeWhat it does
    display: gridCreates a grid container.
    grid-template-columnsDefines the columns.
    repeat(3, 1fr)Creates three equal-width columns.
    1frRepresents a share of available grid space.
    gapCreates spacing between grid items.

  4. Use cases

    • Card layouts.
    • Product galleries.
    • Image grids.
    • Complex page layouts.

4. Flexbox vs CSS Grid

  1. Difference

    FlexboxCSS Grid
    One-dimensional layout.Two-dimensional layout.
    Arranges items primarily in a row or column.Arranges items in rows and columns.
    Useful for navigation and alignment.Useful for cards and larger page layouts.
    Focuses on one direction at a time.Controls rows and columns together.

  2. Remember

    Flexbox and Grid can be combined in the same webpage.
