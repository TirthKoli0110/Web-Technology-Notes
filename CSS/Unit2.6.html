HTML - Formatting & Other Elements

Web Technology  /  HTML  /  Topics 4 to 10

This page compares similar formatting tags and covers quotation, abbreviation, address, citation and text-direction elements.

4. Important Differences

  1. <b> vs <strong>

    <b><strong>
    Bold onlyBold + Important meaning

    This is Bold Text
    This is Strong (Important) Text

  2. <i> vs <em>

    <i><em>
    Italic onlyItalic + Emphasis

    This is Italic Text
    This is Emphasized Text

  3. <del> vs <ins>

    <del><ins>
    Deleted TextInserted Text

    Old Price ₹500
    New Price ₹400

5. <blockquote>

  1. Purpose

    Displays a long quotation.

  2. Syntax

    <blockquote cite="https://example.com">
This is a quotation.
</blockquote>

  3. Output

    This is a quotation. It is displayed as a separate block and is automatically indented by the browser.

  4. Features

    Block-level element
    Browser indents the text
    cite stores the source URL

  5. Remember

    Big Quote 📖

6. <q>

  1. Purpose

    Displays a short quotation. The browser automatically adds quotation marks.

  2. Syntax

    <p>He said <q>Hello</q></p>

  3. Output

    He said Hello.

  4. <q> vs <blockquote>

    <q><blockquote>
    Short quoteLong quote
    InlineBlock-level
    Inside sentenceSeparate block
    Adds quotation marksIndents text

  5. Remember

    Q = Quick Quote

7. <abbr>

  1. Purpose

    Defines an abbreviation.

  2. Syntax

    <abbr title="World Health Organization">WHO</abbr>

  3. Output

    WHO

  4. Examples

    HTML
    CSS
    WHO
    ATM
    ASAP

    Note: Hover the mouse over the abbreviation to see its full form.

8. <address>

  1. Purpose

    Displays contact information.

  2. Syntax

    <address>
Written by John Doe<br>
Example.com
</address>

  3. Output

    Written by John Doe
    Example.com
    Email: john@example.com
    Phone: +91 9876543210

  4. Can include

    Address
    Email
    Website
    Phone Number
    Social Media

9. <cite>

  1. Purpose

    Specifies the title of a creative work.

  2. Syntax

    <p>
<cite>The Scream</cite> by Edvard Munch
</p>

  3. Output

    The Scream by Edvard Munch

  4. Can be used for

    ✅ Book
    ✅ Movie
    ✅ Song
    ✅ Painting
    ❌ Person's Name

10. <bdo>

  1. Full Form

    Bi-Directional Override

  2. Purpose

    Changes the direction of text.

    <bdo dir="rtl">Hello</bdo>

  3. Example

    Normal Text: Hello

    RTL Text: Hello

    LTR Text: Hello

  4. Values

    ValueMeaning
    rtlRight → Left
    ltrLeft → Right

  5. Used for languages

    Arabic
    Hebrew
    Persian
